# 감정 아이콘·왁뿌볼 웹 반영 준비

## 반영 범위

- 기준: 원격 main `56c9396`, 준비 브랜치 `fix/emotion-wax-web`.
- 대표 감정 선택 버튼에 캘린더와 같은 감정 이미지를 표시한다. 추가 감정 버튼은 글자만 유지한다.
- 공통 연결: 억울함→슬픔, 답답함→모르겠음, 외로움→우울함, 허무함→서운함. 표시 이미지 연결이며 감정 이름과 API 값은 변경하지 않는다.
- 하트 상단의 얇은 두 조각을 인접 영역에 포함해 9→7셀로 재분할하고 파편 애니메이션이 끝까지 사라지도록 한다. 누른 셀만 파괴, 전체 파괴 후 말랑한 조작, 대기 복원은 유지한다.
- 구름의 내부 색은 기존 그대로 두고 외부 껍질에만 12% 하늘색 틴트를 적용한다. 원화의 광택·투명 윤곽을 유지하며 파편/복원에도 같은 껍질 텍스처를 사용한다.
- 버터 동작·음원·로그인·수면·백엔드·API 프록시 설정은 변경하지 않는다.

## APK와의 분리

이번 웹 브랜치에는 Capacitor 의존성, Android 프로젝트/아이콘, APK 빌드 스크립트, Android 전용 API 주소 설정을 포함하지 않는다. 기존 package/lock/tsconfig/Vite/Vercel 설정은 main과 동일하다. APK 소스와 산출물은 별도 `spike/android-apk` worktree에 보존한다.

- 기존 Vercel `chosm0204/teslang` (`prj_UiTnP551zFUT59ArVeMgQQ3Vd6Zr`), 운영 주소 `https://teslang-xi.vercel.app`.
- Vercel CLI로 접근 및 Node 24.x / Vite / npm ci / npm run build / dist 설정 확인. 연결 앱의 조회 권한 오류는 기존 CLI 인증으로 확인했으며 계정이나 토큰을 변경하지 않았다.
- Git 자동 배포 미연결 상태 유지. 승인된 웹 변경 커밋 → PR → main 반영 → main 커밋만 담은 깨끗한 배포 폴더에서 수동 Production 재배포 → 운영 화면/경로/API 회귀 확인 순서.

- 로컬 검증을 완료했고 사용자 승인에 따라 PR 병합과 재배포를 진행한다. 운영 검증은 배포 후 별도로 확인한다.
