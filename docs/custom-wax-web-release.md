## 운영 확인

전용 QA 계정 사용, 비밀번호·토큰·사진 원본은 Git/배포물에 미포함.

- Chromium: 실제 로그인, 사진 생성 중 서버 POST 없음, 새로고침 후 재선택, 동일 위치 연타, 전체 파괴 후 드래그·복원, 삭제 후 버터 복귀, 채팅 진입, 보관함·기존 기록 상세 새로고침 통과. 페이지 JS 오류 0.
- WebKit: 실제 로그인, 사진 생성·재선택·연타·전체 파괴·조작·복원·삭제, 채팅 진입·보관함 확인. 기록 직접 조회와 새로고침은 별도 실행에서 인증/기록 API 200으로 확인. 별도 기록 검사 JS 오류 0.
- WebKit 연속 탐색 검사 중 로딩 시간 초과 및 계정 확인 실패가 한 번 나타남. 전체 load/애니메이션 프레임 대기 대신 화면 준비 조건과 제한된 입력 루프를 사용하고 기록 조회는 인증+데이터 조회를 기다리는 별도 검사로 통과. 인증 오류의 근본 원인이 해결됐다고 단정하지 않으며 인증 코드를 수정하지 않음.
- 마우스와 합성 pointer 이벤트를 함께 사용. 실제 휴대폰·스피커 검증, 신규 상담 완료/새 기록 생성은 이번 배포 검증 범위 밖. 기존 저장 기록을 조회함.

APK 소스와 산출물은 그대로 유지. Git 자동 배포 연결은 변경하지 않고 승인된 main 파일만 수동 배포. 기존 원본 작업 폴더의 미커밋 문서는 보존.
