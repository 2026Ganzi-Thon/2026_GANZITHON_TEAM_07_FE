# 문서 차이와 미정 사항

> 확인일 2026-11-13. 노션 문서끼리 비교한 결과다. 이 표는 새로운 요구사항이나 추천안을 확정하지 않으며, 사용자가 채팅에서 답한 결정도 가져오지 않았다. ‘미정’은 이번에 확인한 노션 근거만으로는 확정되지 않는다는 뜻이다.

## 서로 다른 표현·우선순위

| 항목 | 원문의 서로 다른 내용 | 보관 시 처리 |
|---|---|---|
| 누적 분석·개인화 범위 | N02 §15는 통계·누적 분석·과거 대처 추천 후순위. N03의 감정 빈도·개인화 인사이트·과거 기록 기반 조언 등 일부 행은 P0 | 장기 방향과 MVP·명세 중요도를 분리해서 기재 |
| 감정 강도 범위·중요도 | N02 §15·N09·N11은 전후 0~10 직접 입력. N03 5.3.4는 ‘ex) 1~10단계’, P2 | 1~10 예시를 0~10 규격으로 조용히 고치지 않음 |
| 부가 감정 필수 여부 | N02·N11은 대표 1개+부가 1개, N09는 최대 2개, N13은 필수 여부 확인 필요 | 최대 개수와 최소 필수 개수를 구분, 필수 여부 미정 유지 |
| 전체 감정 목록 | N02 추천 표는 6개 감정. N09·N12에는 다른 감정 예시도 있음 | 추천 표를 최종 허용 목록으로 취급하지 않음 |
| OPEN 완료 | N11은 구체적인 사건이 나오면 완료. N13 마지막에는 짧은 첫 메시지 추가 질문 여부를 남은 결정으로 기재 | v4의 규칙과 후속 문서의 미정 표기를 모두 보존 |
| 단계 전환 시 질문 | N11은 완료 시 다음 단계 첫 질문 포함. N13은 질문하는 단계로 넘어가면 기존 질문을 버리고 재호출 | 프롬프트 규칙과 서버 보강 절차를 구분 |
| 정리 저장 시점 | N02 §12 루프는 말랑이 체험 뒤 기록 축적. N02 §11은 상담 종료 후 기록 생성. N13은 정리 결과 저장 처리 | 개념 루프만으로 저장을 체험 완료 뒤로 강제하지 않음. 실제 시점 확정은 별도 |
| 기본 말랑이 복원 시간 | N02는 3초 무조작 후 5초 복원 안. N03 2.1.5 비고는 3초 무조작 후 6초 복원 제안 | 어느 값도 임의 확정하지 않고 출처별 수치 유지 |
| 말랑이 종류의 범위 | N02는 세 종류와 추천을 설명하지만 §15는 ‘다양한 말랑이 유형’을 후순위로 분류. N03 조작·종류별 중요도도 다름 | 세 종류 정의와 이번 제작 범위 확정을 별개로 취급 |
| 생각·욕구 문장 형식 | N11은 사용자 표현을 유지하도록 함. N13은 원문 그대로인지 서술형으로 맞출지 남은 결정 | 저장 표현을 자체 통일하지 않음 |
| AI 처리 방식 | N13 앞부분은 A/B를 검토, 11월 11일 수정사항은 A+서버 보강으로 보고 | 같은 페이지 안에서도 초기 검토와 날짜 있는 수정사항을 구분 |

## 원문이 확인 필요로 남긴 항목

N13의 확인 필요·남은 결정 목록에는 다음이 들어 있다.

- 추천 매핑의 기획 확정 여부
- 말랑이 추천 사유를 LLM이 생성할지
- 1~2줄 전체 요약을 정리 화면 문장과 따로 받을지
- 부가 감정 필수 여부
- 같은 응답의 `risk_flag`를 2차 위험 확인에 사용할지
- OPEN의 구체적인 완료 기준
- `thought`·`need`의 저장 문장 형식

N09에는 내부용 `thought_pattern` 추가와 ‘원하는 결과’를 별도 항목으로 둘지 등의 제안도 있다. 이것들을 구현 완료 사실로 바꾸지 않았다.

## 이 자료에서 완전한 규격을 확인할 수 없었던 부분

| 영역 | 확인되지 않은 내용 | 근거의 한계 |
|---|---|---|
| 감정 입력 | 전체 목록·코드, 목록 밖 입력, 두 감정 추천 충돌 처리 | 추천 표·예시는 있으나 완성된 입력 계약이 없음 |
| 점수 입력 | 대표/전체 중 평가 대상, 초기값, 양끝 문구, 건너뛰기 | 직접 입력·0~10 원칙만으로 화면 세부 동작을 결정할 수 없음 |
| 종료·이탈 | 종료 버튼과 확인창, 뒤로가기, 재접속, 감정 선택 전 종료 결과 | 종료 의사 처리와 구체적인 화면 이탈 정책은 서로 다름 |
| 모름 횟수 | 같은 단계에서 중간에 다른 답이 왔을 때 초기화 여부 | 두 번째에 넘기는 규칙만으로 연속/누적을 확정할 수 없음 |
| 인증 | 최종 로그인 방식·요구 시점, API 계약 | 여러 로그인 기능이 적혀 있지만 채택 확정과 같지 않음 |
| API | 전체 엔드포인트·오류·인증·타입·배포 주소 | N14는 비어 있고 N13은 부분 변경안임 |
| 저장·삭제 | 원 대화/AI JSON까지 삭제되는 범위·보존 기간 | 삭제 및 분석 제외 방향과 완전한 데이터 정책은 다름 |
| 체험 자산 | 최종 음원, 말랑이 시각 자산, 전체 동작 규격 | 화면 예시와 문서 요구는 있으나 자산 준비 완료 자료는 아님 |

이 목록은 보관 자료를 읽을 때의 한계를 표시한 것이다. 모든 항목에 대해 지금 새 기획을 하거나 질문해야 한다는 우선순위 목록은 아니다.
