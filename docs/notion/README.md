# 테슬랑 노션 자료 보관본

**2026-11-13에 확인한, 승인 범위 19개 페이지의 로컬 자료집**이다. 노션 원본·복제본과 기존 `prd.md`는 수정하지 않았다.

노션에 있는 내용과 제안·예시·미정 상태를 정리했다. 채팅에서 합의한 결정, 백엔드 GitHub 내용, Figma 파일과 채팅 첨부 이미지는 섞지 않았다. 이 자료집은 확정 개발 PRD를 대체하지 않는다.

## 보관 구조

- `원문/`: 내용이 있는 14개 페이지의 MD, 첨부 이미지 10장, CSV 4개. 11개 페이지는 내보내기 원본 그대로, 3개는 화면 전사본이다.
- `내보내기/`: Notion이 생성한 ZIP 11개. 재추출·비교할 수 있도록 원본 그대로 보관했다.
- `주제별/`: 서로 관련된 내용을 재구성한 문서 12개와 전체 기능표 2개. 요약이며 원문 전체를 대체하지 않는다. AI 문서는 읽기용 전체 본문도 함께 제공한다.
- `수집기록.json`: 실제 보관한 14개 페이지의 파일·수집 방식.
- `페이지분류.json`: 승인한 19개 페이지와 사용자가 제외한 연결 페이지 5개의 상태.

API 명세서의 빈 페이지, BE·FE의 작업 틀, AI 프롬포트와 P&D의 연결 구조는 페이지목록에 남겼다. 별도 빈 MD를 만들어 내용이 있는 문서처럼 보이게 하지 않았다. 짧은 로드맵과 이미지 중심 와이어프레임은 실제 내용이 있어 보관했다.

## 출처와 이용 기준

각 주제 문서 상단의 N번호는 [페이지목록](페이지목록.md)의 출처 번호다. 로컬 보관본과 노션 원본 링크를 함께 제공한다. 페이지 안 링크가 범위 밖 자료로 이어지면 링크만 유지하며, 그 본문을 읽었다고 간주하지 않는다.

원문은 자동으로 동기화되지 않는다. 노션이 바뀌면 확인일과 변경 부분을 대조해 갱신해야 한다. 주제 요약보다 정확한 문구가 필요하면 원문을 확인한다. 노션 내보내기의 코드블록·줄바꿈 등 형식은 원문에서 보존했으며, 읽기용 문서에서만 일부 서식을 정돈했다.

수집 범위는 승인한 페이지의 표시 본문·표·첨부 이미지다. 댓글·수정 이력·권한·링크된 모든 하위 문서까지 복제한 것은 아니다. 외부 링크는 온라인 접속이 필요하지만 보관한 이미지와 파일은 로컬에서 열 수 있다.
