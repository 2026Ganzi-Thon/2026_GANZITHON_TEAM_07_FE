# 추가사항

## 1. Thought 분리

소크라테스 문답법은 질문과 답을 주고받는 과정에서 사용자가 직접 새로운 생각을 만들어 가는 대화법입니다.
그래서 소크라테스 문답법을 제대로 반영하려면 생각을 대화 전과 대화 후로 나누는 것이 좋을 것 같습니다.

- `thought`: 대화 전 생각
- `alternative_thought`: 대화를 통해 새로 떠올린 다른 관점

## 2. 감정 강도 분리

- `intensity_before`: 대화 전 감정 강도
- `intensity_after`: 대화 후 감정 강도

Thought와 같은 이유로 감정 강도도 대화 전후로 나누는 것을 제안합니다.
대화를 통해 감정이 실제로 얼마나 달라졌는지, AI 대화가 사용자에게 얼마나 도움이 되었는지를 수치로 확인할 수 있습니다.
또 이런 기록이 쌓이면 어떤 대화나 관점이 감정을 낮추는 데 효과가 있었는지 개인화 분석의 근거로도 쓸 수 있습니다.

감정 강도는 AI가 예측하지 않고, 사용자가 직접 0~10으로 매기는 방식을 제안합니다.

## 3. coping 추가

SFBT의 대처 질문("이런 와중에도 어떻게 버텨 왔어요?")에 대한 답을 남기는 칸입니다.
기록이 쌓이면 사용자에게 실제로 효과가 있었던 버티는 방법을 다시 추천하는 개인화 근거로 쓸 수 있습니다.

## 4. Need를 끌어내는 질문 추가

현재 구조에 Need(실제로 원하는 것)가 있지만, 대화 흐름에는 욕구를 직접 묻는 질문이 없습니다.
감정을 고른 뒤 "그때 사실 바랐던 건 뭐였어요?" 같은 질문을 하나 넣어 Need를 사용자가 직접 말하도록 하는 것을 제안합니다.

느낌 뒤에 있는 욕구를 묻는 방식은 비폭력대화(NVC)에서 주로 쓰는 개념이라 근거로 함께 적으면 좋을 것 같습니다.

- 참고: [https://www.krnvc.org/page/sub2_1](https://www.krnvc.org/page/sub2_1)

## 5. Emotion 여러 개 허용

예시처럼 "서운함 / 분노"가 함께 나타나는 경우가 많아서, 대표 감정 1개 + 함께 느낀 감정 1개, 최대 2개까지 고를 수 있게 하는 것을 제안합니다.

## 6. thought_pattern 추가 (내부용)

사용자의 대화 전 생각(`thought`)이 어떤 생각 패턴인지 AI가 내부적으로 태그합니다.

- 예: "내 노력을 인정하지 않는 것 같다" → 다른 사람의 마음을 단정하는 패턴

사용자에게는 대화 중에 보여주지 않고, 기록이 쌓이면 "이번 달엔 다른 사람이 나를 어떻게 생각할지에 대한 생각이 자주 나왔어요"처럼 쉬운 말로 풀어서 개인화 인사이트로 보여주는 데 사용합니다.

## 7. 원하는 결과 정리

분석 대상에는 "원하는 결과"가 있지만 구조화 항목에는 없어서, Need에 합칠지, Action에 합칠지, 따로 둘지 정하면 좋을 것 같습니다.

(Need는 사용자의 욕구, Action은 사용자의 행동에 초점을 둔 항목이라 생각해서 이렇게 정리해 보았습니다!)

## 8. 위기 대응 추가

사용자가 자해·자살 등 위험한 표현을 하면 질문을 멈추고 상담 기관 연결 화면으로 넘어가는 처리가 필요합니다.
정신건강 서비스라 심사에서도 거의 확실히 나올 질문이라, 대화 설계에 함께 명시하는 것을 제안합니다.
자세한 내용은 아래 **위험 대응 규칙**을 참고해 주세요.

# 위험 대응 규칙

정신건강을 다루는 서비스이기 때문에, AI 대화 전체에 아래 규칙을 항상 적용합니다.

## 1. 위험 신호 감지

- 서버 규칙으로 먼저 검사하고, AI가 한 번 더 확인합니다. (AI 판단 하나에만 맡기지 않음)
- 감지 대상: 자해·자살 생각, 타인을 해치려는 생각, 학대·폭력 피해 등
- 애매한 표현은 위험 신호로 보고 처리합니다. 다만 "과제 때문에 죽겠다 ㅋㅋ"처럼 과장된 일상 표현이 분명하면 예외로 둡니다.

## 2. 감지했을 때 AI의 행동

- 진행 중이던 질문, 생각 정리, 다른 관점 찾기를 바로 멈춥니다.
- 사용자의 마음을 짧게 받아 준 뒤, 혼자 견디지 않아도 된다고 말하고 상담 연결 화면으로 넘어갑니다.
- 해결책 제시, 설득, 훈계, "괜찮아질 거예요" 같은 가벼운 위로는 하지 않습니다.

## 3. 상담 연결 화면

- 자살예방상담전화 109 (24시간)
- 정신건강위기상담전화 1577-0199 (24시간)
- 청소년 상담 1388
- 긴급 상황 112 / 119

화면을 닫아도 보관함이나 메뉴에서 언제든 다시 볼 수 있게 합니다.

## 4. AI가 항상 하지 않는 것

- 진단하거나 병명을 언급하지 않습니다.
- 약물, 치료 방법 등 의료적인 조언을 하지 않습니다.
- 자신을 상담사나 전문가라고 소개하지 않습니다.
- 사용자의 생각을 "잘못됐다", "비합리적이다"라고 평가하지 않습니다.

## 5. 서비스 고지

첫 사용 시와 설정 화면에 "이 서비스는 전문 상담이나 치료를 대신하지 않습니다"를 안내합니다.

## 6. 위험 기록 처리

- 위험 신호가 감지된 대화는 `risk_flag`로 표시해 저장합니다.
- `risk_flag` 기록은 개인화 인사이트에 사용하지 않습니다.
- 사용자가 지우면 다른 기록과 똑같이 삭제됩니다.

# 감정 데이터 저장 구조 제안

- `situation`: 현재 상황 (예: 친구와 갈등) / AI 정리, 필수
- `trigger`: 감정을 유발한 사건 (예: 친구의 무시하는 말) / AI 정리
- `thought`: 대화 전, 그때 스친 생각 (예: 내 노력을 인정하지 않는 것 같다) / AI 정리
- `emotions`: 느낀 감정, 최대 2개이며 첫 번째가 대표 감정 (예: 서운함, 분노) / 사용자 선택, 필수
- `need`: 실제로 바란 것 (예: 인정받고 싶음) / AI 정리
- `intensity_before`: 대화 전 감정 강도, 0~10 (예: 8) / 사용자 입력, 필수
- `alternative_thought`: 대화 후 새로 떠올린 다른 관점 (예: 친구가 예민한 상태라 말이 거칠게 나왔을 수도 있다) / AI 정리
- `coping`: 힘들 때 버텨 온 방법 (예: 다른 친구에게 털어놓으며 버텼다) / AI 정리
- `action`: 앞으로 해볼 행동 (예: 내일 친구에게 서운했다고 말해 보기) / AI 정리
- `intensity_after`: 대화 후 감정 강도, 0~10 (예: 5) / 사용자 입력, 필수
- `thought_pattern`: 생각 패턴 태그, 내부용으로 사용자에게 보여주지 않음 (예: mind_reading) / AI 태그

**구분**

- **AI 정리**: 사용자와의 대화 내용을 바탕으로 AI가 정리하는 항목입니다. 사용자가 직접 말한 내용만 정리하고, 말하지 않은 항목은 추측해서 채우지 않고 빈칸으로 둡니다.
- **사용자 입력·선택**: AI가 추측하지 않고 사용자가 화면에서 직접 채우는 항목입니다.
- **필수**: 대화가 정상적으로 끝났다면 반드시 값이 있어야 하는 항목입니다. `trigger`와 `thought`는 최대한 채우되, 사용자가 끝까지 구체적으로 말하지 않을 수 있어 빈칸을 허용합니다. (사용자가 그냥 계속 짜증났다고만 하면 채우기가 답이 없을 것 같습니다.)
