# 자료

심리 치료란 심리적 문제(예: 심리적 고통이나 해결하고자 하는 문제 등)를 심리치료 전문가와 대화를 통해 해결하는 과정으로, 단순히 문제해결 뿐만 아니라, 자기이해를 통해 궁극적으로 행복해지는 방법을 찾아 나가는 과정입니다. 위 서비스에서는 전문적인 상담이 부담되는 현대인들의 고민들을 AI가 대신하여 들어주고 대화를 통해 생각을 발전시키고 감정을 끌어낼 수 있도록 돕습니다.

AI는 인지행동치료(CBT, Cognitive Behavioral Therapy)를 참고하여 사용자와 대화를 시도하며 사용자가 상황, 문제를 새롭게 지각하고 재해석하며 보다 합리적이고 긍정적으로 행동할 수 있도록 돕습니다.

[인지행동치료](https://app.notion.com/p/40b5b968a98b8052bd40eb30e8ad856d)

[소크라테스 문답법](https://app.notion.com/p/40b5b968a98b8090845cebedf688f302)

소크라테스식 대화법은 단순한 기술이 아니라, 내담자를 하나의 온전한 인격체로 존중하며 함께 진리를 탐구해 나가는 태도입니다.

[해결중심 단기치료 (SFBT 척도)](https://app.notion.com/p/40c5b968a98b80dcb281f890b80d719a)

해결중심 단기치료(SFBT)는 문제의 원인을 파고드는 대신, 사용자가 이미 가진 강점과 문제가 덜했던 순간에 주목해 작은 변화를 만들어 가는 접근입니다. 특히 척도 질문은 지금 상태를 점수로 표현하게 하고, "그래도 이 점수까지 버틸 수 있었던 건 무엇 덕분인지"를 물어 사용자가 스스로의 힘을 발견하도록 돕습니다.
