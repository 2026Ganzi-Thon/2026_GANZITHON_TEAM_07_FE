## 자료의 성격

N04의 제목은 **와이어프레임 (예시)**이며 이미지 두 장으로 구성된다. 이를 확정 디자인·컴포넌트 규격·실제 작동하는 프로토타입으로 바꾸어 해석하지 않는다. 이번 자료에는 Figma 파일이나 사용자가 채팅에 첨부한 보라색 프로토타입 이미지를 가져오지 않았다.

## 화면별로 확인되는 요구

| 화면 | 원문에 있는 구성·행동 | 아직 이 자료만으로 정할 수 없는 것 |
|---|---|---|
| 메인 | 중앙 기본 말랑이, 우측 하단 원형 메뉴, 말랑이 체험 또는 기록 진입 | 최종 크기·간격·글꼴·색상 토큰 |
| 대화 | 텍스트 입력, 짧은 공감과 질문, 단계에 따라 감정·점수·행동 선택 | 최종 메시지 컴포넌트, 키보드·스크롤·오류 UI |
| 감정 입력 | 사용자가 감정과 사전 강도를 입력 | 확정 목록, 직접 입력 가능 여부, 초기값·양끝 문구 |
| 정리·추천 | 대화 항목 정리, 전후 점수, 추천 연결 | 카드 순서, 전체 요약과 항목 요약을 함께 보여줄지 |
| 기록함 | 달력·날짜별 상세 | 비어 있음·로딩·오류 상태의 완성 화면 |
| 수면 모드 | 소리·느린 시각 효과·타이머 | 확정 음원과 동작 자산 |
| 상담 연결 | 위험 시 안내, 평소에도 접근할 수 있는 연결 메뉴 | 세부 디자인과 배치 |

## 자산과 구현의 구분

정리한 것은 화면 참고 이미지와 문서상 UI 요구다. 버튼의 전체 상태, 반응형 기준, 접근성 수치, 말랑이 애니메이션 규격 등은 이 그림만 보고 확정값으로 기록하지 않는다. 플로우 이미지 5장은 [사용자흐름](사용자흐름.md)에서 함께 확인할 수 있다.
