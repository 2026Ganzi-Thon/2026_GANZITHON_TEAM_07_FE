## 팀 메인

N01은 서비스 문서, 프로젝트 링크, 참여자, 진행 상황을 연결하는 시작 페이지다. 역할은 P&D·FE·BE로 나뉜다. 이름·연락처가 포함된 팀 메인 원문은 보관하되, 관련 없는 주제 문서에 연락처를 반복하지 않았다.

## 10/26 회의 본문

원문 표기 시간은 **10/26 pm 10:00~11:20**이다.

- 각자 준비한 아이디어 공유와 정신·심리 건강 케어 안에서 서비스 방향 정하기
- 대략적인 전체 일정 정하기
- 협업 방식 논의
- ‘마음말랑이’와 ‘생각 분리수거’를 결합하는 아이디어 기록
- ‘재질 터치 → 현재 감정 선택 → 필요한 행동 실행 → 마음 오브젝트로 기록’이라는 초기 흐름
- 10월 29일 목요일 오후 11시까지 아이디어 구체화와 간단한 기획 준비

이 내용은 승인한 회의록 페이지 안의 본문이다. 연결된 ‘마음말랑이’·‘생각 분리수거’ 개별 페이지는 사용자 요청에 따라 열지 않았다.

## 10/29 회의

승인한 페이지에는 ‘10/29 pm 11:00~’ 제목과 별도 회의록 링크만 있다. 연결 페이지는 이번 범위에서 제외했다. 따라서 실제 회의 내용은 이 정리의 근거가 아니다.
