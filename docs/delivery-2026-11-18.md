## 포함하지 않은 파일과 검증 경계

- 이전 실험, 개인 일지, 환경 파일, 의존성, 빌드·QA 산출물은 포함하지 않는다.
- 녹화에서 추출한 왁스 WAV는 로컬 비교용이다. Git·public·dist에 포함하지 않으며 기본 실행은 독립 합성음을 사용한다.
- 꾹꾹체는 기존 협의대로 유지했다. 최종 배포 전 대체 서체와 파일·이력 정리는 디자인 담당자와 협의해야 한다.
- 실제 로그인 전체 흐름·수면모드·백엔드 연결은 후속 담당 범위다. MSW 기록은 탭 메모리에만 유지된다.
- 음성은 입력 전용이며 답변 읽기는 하지 않는다. 가상 인식 이벤트로 전사·오류·복귀를 검증했으나 실제 한국어 음성 인식 서비스 연결은 미해결이다.
- 버터/구름 전체 파괴 후 안쪽 조작과 하트 국소 벗겨짐은 비교 구현으로 남아 있다. 공통 최종 동작으로 통일한 상태는 아니다.
