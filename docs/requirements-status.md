# 필수 기능별 구현 현황

## 말랑이 재질 업데이트 · 2026-11-18

버터 원화 교체, 하트의 전체 파괴 후 조작 흐름 통일, 제공 음원과 움직임에 반응하는 슬랑이 지속음을 반영했다. 최종 동작·코드·출처·재현 절차는 [변경 명세](design/material-refresh-2026-11-18.md)를 따른다. 최종 확인한 왁뿌볼 추출 WAV3개를 프로젝트에 포함해 일반 실행과 로컬의 소리를 통일했다. 별도 환경변수나 원본 영상은 실행에 필요하지 않다.

## D54 — 상단 정렬·제공 자산 교체 (2026-11-17)

말랑이 체험의 종류 선택·소리·메뉴를 기존 종류 선택 높이(일반 화면 top80px+safe area)에 한 줄로 배치한다. D55 보완으로 하단은 중앙의 체험 마치기만 남기고 메인의 초기화 버튼은 제거했다. 제공 PNG를 음성 채팅 아이콘/석상·MY 프로필에 연결했다. 메뉴 PNG는 형태 참고로만 보존하며, 실제 상단 메뉴는 반투명 유리 효과와 버튼 내부 아이콘·글자 묶음 중앙 정렬을 사용한다. 추천의 남은 문장 카드에는 Pretendard(라벨500/본문600)를 쓰고 메인 하단 문구/화살표 간격은5px로 줄였다. 기존 대화·음성·기록 동작은 유지한다.

## D53 — 하트 길게 누르기·왁스 벗겨짐 (2026-11-17)

하트는 꾹 누르는 동안 파열음을 이어 재생하고, 접점 주변 왁스 일부가 들려 안쪽 색상이 드러난다. 짧은 누름은 구김 중심이며, 손을 떼면 소리는 멈추고 원본으로 복원된다. 버터·구름의 전체 파괴 후 조작 규칙과 로컬 음원 범위는 유지한다.

## D52 — 버터/하트 비교 구현 (2026-11-17, 로컬 검토)

버터는 접점 한 조각 안의 작은 파편이 접혔다 떨어지며 **전체 파괴 후에만 안쪽 조작**을 허용한다. 하트는 별도 비교안으로 **누른 주변의 면이 구겨졌다가 손을 떼면 원본으로 돌아오며**, 껍질 파괴/안쪽 단계가 없다. 구름은 D51을 유지한다. 최종 공통 동작은 미확정이다. 버터·하트는 제공 녹화에서 추출한3개 효과음을 로컬에서만 사용한다. 파일은 Git 제외 artifacts에 두고 Vite 미들웨어로 제공하며 public/dist에 포함하지 않는다. 공개 재사용 조건은 미확인이다. 로그인·수면·음성은 변경하지 않았다.

[동작·로컬 음원 설정·검증](design/wax-comparison-2026-11-17.md).

## D51 — 이전 기준

### D51 — 전체 파괴 후 조작·거친 균열음 (2026-11-17, 로컬 검토)

**껍질을 모두 깨뜨린 뒤에만 안쪽을 누르고 늘릴 수 있다.** D50의 부분 파괴 중 안쪽 조작은 제거했다. 이미 깨진 곳을 다시 눌러도 다른 조각을 깨뜨리거나 부드러운 효과음을 내지 않는다. 전체 파괴 후 조작·손 떼기·대기·껍질 복원 흐름과 작은 가장자리 조각 보정은 유지한다. 파열음은 음높이가 있는 성분을 빼고 낮고 거친 균열과 촘촘한 잔파열을 겹치는 독립 합성음으로 수정했다. 참조 사이트 음원/코드는 복사하지 않았다. 로그인·수면·음성은 유지한다.

[동작·출처·검증 경계](design/wax-complete-crunch-2026-11-17.md).

## 이전 적용 — D42: 설정 복귀와 결과 첫 화면 경계 (2026-11-16)

- 설정 진입 시 내부 출발 경로와 필요한 화면 상태를 함께 전달한다. 상단 뒤로가기는 출발 화면으로 복귀하며 보관함의 월간/주간/목록·기준 월·선택 날짜를 유지한다. 말랑이 종류 쿼리와 결과 기록 ID도 유지한다. 직접 설정 진입처럼 출발 정보가 없으면 메인으로 간다.
- 설정에서 도움/기록 관리로 이동했다 돌아와도 최초 출발 경로를 유지한다. `SettingsLink`와 `settingsReturnFor`를 공통 진입점으로 사용하며, `Page.backState`로 복귀 상태를 전달한다. 실제 로그인 흐름은 이번 범위가 아니다.
- 결과 첫 화면은 ‘저장된 기록 확인하기’까지 배치한다. 저장 완료 안내/상세는 다음 스크롤 영역에 둔다. 남는 높이는 추천 카드/그림에 배분하고 링크 아래에는 기본12px 여백과 기기 안전 여백만 둔다. 긴 내용은 스크롤을 유지한다.

## 이전 적용 — D39 (2026-11-16)

- **대화 진행:** 프론트 예시 응답의 사건 단어 목록/9자 제한을 제거했다. 보통 문장은 감정 선택으로 진행하고, 명백히 막연한 첫 문장은 한 번만 더 묻는다. 다음 의미 있는 답은 진행하며 ‘이 내용으로 계속하기’도 제공한다. 자음·기호만 입력하면 전송 전 입력창에서 안내하고 반복 AI 질문을 추가하지 않는다. 사용자 문장만 보관하며 서버의 사건 판단 규칙을 확정한 변경은 아니다.
- **종료 확인:** 보관은 진한 기본 버튼, 계속 대화는 테두리 버튼, 저장 없이 나가기는 구분선 아래 붉은 보조 동작이다. 감정 선택 후에는 점수 마무리도 유지한다. 저장 없이 나가기는 어떤 단계에서든 현재 대화를 보관하지 않고 메인으로 이동한다. 대화의 단계 캡션과 하단 ‘전문 상담이나 치료를 대신하지 않아요.’ 문구는 제거했다.
- **기록 상세:** Figma ‘마음 보관함 기록 선택’ 구성에 맞춰 요약·전후 점수·입력한 생각/실천을 한 카드에 넣고, 하단에 숨기기·삭제·자세히 보기를 배치한다. 상단 삭제와 외부 가리기 버튼은 제거했다. `?view=conversation`은 같은 기록의 전문 보기 상태이고 뒤로가기로 요약에 복귀한다. 가린 내용 보호·MY 복원·집계 제외는 유지한다. 없는 점수/관점/사용 이력은 생성하지 않는다.
- **메인 말풍선:** 투명 캔버스 경계 대신 양의 실제 보이는 상단을 기준으로 붙인다. 아이보리 둥근 면·작은 꼬리·얕은 그림자, 0.55초 등장과 4.8초 주기의 3px 떠오름을 적용한다. 호흡은 그림에만 적용해 클릭 영역을 고정하고 줄인 모션에서는 정지한다. 새 말풍선 모양/모션은 승인된 웹 보완안이며 Figma 원본 효과를 측정해 복제한 값은 아니다.
- **음성 경계:** 실제 사이드패널 브라우저에서 인식 서비스 `network` 오류를 재현했다. 시작 이벤트가 10초간 없으면 연결 대기를 끝내고, 결과 없는 종료의 자동 재시작은 1회로 제한한다. 오류 시 경과시간을 멈추고 초안을 보존하며 재시도/글로 계속하기를 제공한다. 브라우저 서비스 연결 실패 자체는 해결 확인되지 않았다. 실제 전사 성공·한국어 인식 품질과 가상 이벤트 QA를 구분한다.
- **범위:** 로그인 전체 흐름·수면은 변경하지 않았다. 실제 AI·인증·영속 DB/STT 백엔드 미연동, 기록은 현재 탭 메모리다. 독립 경로는 9개다. 노션/Figma 원본과 원격 Git은 수정하지 않는다.

## 이전 적용 — D38 (2026-11-16)

- **중간 보관:** 종료 확인창의 ‘여기까지 보관하고 나가기’는 전송한 사용자 메시지가 있을 때만 제공한다. 현재 대화·확정 감정·점수·슬롯을 그대로 저장하고 마음 보관함으로 이동한다. 감정 미선택도 허용하되 추천은 생성하지 않는다. 미입력 점수/슬롯을 채우지 않으며, 작성 중 글·미확정 음성은 저장하지 않는다. 저장 실패 시 대화를 유지하고 같은 ID/스냅샷으로 재시도한다. 정상 완료·사후 점수 경로도 유지한다.
- **기록 가리기:** 삭제와 별도다. 가린 기록은 월간·주간·목록·횟수/평균/감정 집계에서 제외한다. MY → 기록 관리 / 삭제 / 가리기에서 확인하고 다시 표시할 수 있다. 가린 상세는 내용 대신 안내를 먼저 보여주고 ‘이번에만 내용 보기’로 펼친다. 별도 잠금/암호 보호를 뜻하지 않는다.
- **말랑이 선택:** 추천받은 종류가 기본 선택이다. 후보를 누르면 같은 결과 화면의 강조·캐릭터·조작 안내·CTA만 바뀐다. ‘선택한 말랑이 만지러 가기’에서 이동하며 당시 추천 기록은 유지한다. ‘눌러서 바꿀 수 있어요’를 표시한다.
- **짧은 프론트 대화:** 기본 예시 경로는 OPEN → EMOTIONS → PRE → THOUGHT → ACTION → POST → DONE이다. REFRAME/NEED/COPING 타입과 기존 분기 처리는 남기지만 기본 체험에서 추가 질문하지 않는다. 건너뛴 슬롯은 미입력으로 유지한다. 이 변경은 서버 AI 단계 정책의 확정이 아니다.
- **화면:** 음성 석상은 상단 최소72px(낮은 화면64px)을 확보하고 메인 말풍선의 박스 기준 배치는 D39에서 실제 양 그림 기준으로 교체했다. 추천 카드/요약/후보/CTA는 고정 Y 대신 내용 높이를 따라 배치한다. 작은 조언은 산책·휴식·기록 각 3개 문구와 해당 원본 SVG를 연결하며, 사용자 실천이 있으면 그 문장을 우선한다.
- **경계:** 로그인 전체 흐름과 수면은 기존 임시 상태를 유지한다. 실제 AI·인증·영속 DB 미연동. 중간 저장 `partial`, 가리기 `hidden`, PATCH는 프론트 예시 계약이며 서버 지원을 의미하지 않는다. 새로고침하면 체험 기록은 초기화된다. 독립 경로 수는 9개이며 `/archive?manage=1`은 보관함의 관리 상태다.

## 상태를 읽는 방법

- **실제 구현**: 해당 프론트 동작이 코드로 동작한다. 실제 AI·인증·DB까지 연결됐다는 뜻은 아니다.
- **임시 구현**: 예시 응답, 메모리 저장소, 후보 추천표, CSS 캐릭터로 흐름을 확인한다. 실제 기능으로 교체해야 한다.
- **미구현**: 해당 동작이나 연동이 없다. UI가 존재해도 실제 인증·AI 분석·영속 저장을 완료로 처리하지 않는다.

하나의 필수 기능에 세 상태가 함께 있을 수 있다. 아래 표는 이를 한 가지 상태로 뭉뚱그리지 않는다. 코드 링크는 구현 위치이며, 실제 서버 검수의 증거가 아니다.

## 4. 이번에 백엔드 답변 없이 보완한 부분

1. **전체 대화 전달**: 완료 payload에 메시지 순서·역할·내용을 포함한다. 슬롯의 마지막 문장만 전달하던 누락을 보완했다. 저장 실패 후에도 같은 대화 ID와 메시지로 재시도한다. 현재 예시 저장소는 이를 AI로 요약하지 않으며 원문 이력을 기록 DB에 영속 저장하지 않는다.
2. **통신 실패 복구**: 요청 및 응답 본문 수신을 30초로 제한하고 타임아웃/연결/잘못된 JSON 오류를 구분한다. 통신 실패는 사용자가 재시도한다. D32에서 잘못된 대화 응답 구조에 한해 1회 재요청을 추가했고, 저장·삭제는 자동 반복하지 않는다. 전송 문장과 작성 중 초안은 유지한다. 대화 화면을 떠나면 대기 중 답변 요청을 취소한다.
3. **처리 중 팝업**: 삭제·종류 변경 중 닫기/Escape/배경 클릭으로 팝업만 사라지지 않도록 통일했다. 실패 후에는 다시 닫거나 재시도할 수 있다.
4. **조작 중단 처리**: 두 번째 포인터의 해제가 첫 포인터의 드래그를 끝내지 않도록 했다. 창 초점 이탈·탭 숨김·포인터 취소·초점 이동 시 눌림/늘리기를 복원하며 오른쪽 마우스 버튼은 조작으로 세지 않는다.
5. **초기 준비 상태**: 앱 스크립트가 준비되기 전 빈 화면 대신 준비 상태를 표시한다. 초기화 실패 때 준비 안내를 오류·재시도 UI로 교체한다.
6. **응답 검증**: 잘못된 기록·인벤토리를 화면에 바로 전달하지 않는다. 대화 응답의 추가 필드가 감정/점수를 덮어쓰지 않도록 한다. 실제 서버 계약을 확정한 검증은 아니다.
7. **말랑이·소리**: 국소 변형·재료별 복원, 제공 PNG 9개 모양, 공간에 대응하는 껍질 파괴와 CC0 가공 소리를 구현했다. 출처·대안·실기기 잔여 검수는 [조사](toy-research.md)에 기록한다.

30초는 프론트 보호용 구현값이며 운영 AI의 SLA를 확정한 것이 아니다. 요청 취소/타임아웃만으로 서버 처리가 취소됐다고 판단해서는 안 된다. 특히 실제 저장·삭제 연동 시 서버 결과 재조회·멱등 키 계약을 확인해야 한다.

| 첫 입력 | 시트/직접/시작 문구 동일 전송, 이력 포함 보충 사건 처리, 반복 질문 방지 | 로컬 정규식 판별을 실제 AI/서버 단계로 교체 |
| 종료 확인 | 끝내기/화면 안 뒤로가기 확인, 취소 시 초안·메시지·스크롤 유지 | 실제 종료 API, 브라우저 뒤로가기 정책 |
| 음성 | 중간 전사 한 말풍선 갱신, 확정만 1회 전송, 음소거/중단/채팅 보기/텍스트 답변, 권한·네트워크 오류 복구 | 실제 마이크/한국어 인식 검수, 운영 공급자·데이터 처리 계약 |
| 메인 | 방문별 짧은 문구, 그림 호흡, 작은 메뉴 등장/사라짐, 줄인 모션 | 실기기 터치·최종 자산 |
| 결과·MY | 실제 ACTION의 발자국/작은 실천, MY 개발 안내 제거·이름 표시 | 원본 SVG, 실제 프로필 필드와 계정 관리 |

로그인·수면은 사용자 지정 제외 범위로 기존 상태를 유지한다. 브라우저 음성은 자체 백엔드 연결을 필요로 하지 않지만 브라우저 제공자 인식 서비스를 사용할 수 있다. 가짜 전사/듣기 상태로 미지원을 숨기지 않는다. [상세 적용 기록](design/dialogue-voice-2026-11-16.md).
