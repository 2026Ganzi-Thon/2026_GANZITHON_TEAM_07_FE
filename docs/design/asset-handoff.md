# Figma 자산 내보내기 인계표

2026-11-16 갱신. 원본 내보내기 파일을 전달받아 단계적으로 반영한다. Figma 원본은 수정하지 않는다. 아래 파일명은 전달 편의를 위한 제안이며 원래 이름으로 전달해도 된다. 원본 파일: [프로토타입](https://www.figma.com/design/vmbKI4ltraNNxZSlhmg27N/?node-id=71-244).

## PNG — 캐릭터·로고

이미지 레이어/그룹만 선택해 PNG 2x, 배경 투명으로 내보낸다. 그림 자체의 그림자·투명 여백은 유지하고 회색 Figma 캔버스나 화면 배경을 포함하지 않는다. 전체 화면 캡처는 필요하지 않다.

| 제안 파일명 | 선택할 대상 | 사용할 위치 |
|---|---|---|
| `teslang-logo.png` | 석상과 양이 함께 있는 둥근 정사각 로고 (`151:9070`) | 브라우저 탭 favicon·사이트 아이콘. 앱/PWA 도입 아님 |
| `lamb.png` | 일반 양 캐릭터. 메인 이미지 `140:5271` 또는 같은 원본 개별 자산 | 메인·로딩·추천의 표시. 조작 중 Canvas와 결합 방식은 별도 검수 |
| `socrates.png` | 손을 턱에 대고 있는 석상 전신 | 대화 진입·로그인 배경 |
| `socrates-with-toy.png` | 말랑이를 안고 있는 석상 전신 | 관련 진입·음성 화면의 시각 자산. 실제 음성 기능은 별도 |
| `socrates-avatar.png` | 대화창 원형 석상 프로필 | 채팅·저장된 대화 아바타 |
| `lamb-sleep.png` | 보라색 수면 모자를 쓴 양 | 후순위 수면 화면용 보관. 지금 필수 구현을 막지 않음 |

로고 안에 그려진 아이보리 배경은 디자인의 일부이므로 유지한다. 별도 슬랑이/스퀴시/왁뿌볼 이미지가 실제로 제작되어 있다면 함께 전달받되, 공통 양 이미지가 세 종류의 최종 개별 자산이라고 임의 확정하지 않는다.

## SVG — 아이콘

- 기본 사용자 프로필
- 메뉴(≡), 닫기(×), 설정, 뒤로가기, 전송
- 마이크, 음소거, 채팅
- 메뉴 안의 달(수면), 연필(감정 기록), 노트(마음 보관함)

가능하면 아이콘 자체를 SVG로 내보낸다. 원형 배경·테두리·복합 그림자까지 포함한 버튼 컴포넌트는 별도 SVG도 있으면 비교에 사용한다. 누르는 영역과 접근 가능한 이름은 웹 코드에서 제공한다. SVG로 효과가 달라지면 버튼 전체를 PNG 2x로 추가 전달해도 된다. 실제 서버 동작·채팅 입력·달력은 이미지로 내보낼 필요가 없다.

## 서체

제공된 `MemomentKkukkukk.ttf`를 변환 없이 로컬 웹폰트로 연결했다. 메뉴18px, MY 메뉴16px, 추천 제목20px, 동적 요약15px/24.4px는 기존 Figma 측정값을 적용한다. 그 외는 Pretendard다. OTF는 같은 서체의 중복 형식이라 포함하지 않았다.

폰트 파일 제공과 공개 웹 임베딩·재배포 허락은 별개다. 제공 TTF 원본은 이번 저장소 전달분에 포함하며 외부 라이선스 증빙 상태는 [자산 기록](../assets.md)에 남긴다. 고정 글자 SVG는 현재 화면 확인의 선행 조건이 아니다.

## 수령 후 검수

투명도/원본 크기/투명 여백/중복 자산을 확인한 뒤 저장소에 연결한다. PNG는 용도에 맞게 최적화하고 로고에서 favicon을 만든다. 누락 파일은 기존 임시 자산으로 남았다고 기록한다. 출처·파일명·라이선스 정보는 [자산 기록](../assets.md)에 갱신한다. 이미지 교체 후 캐릭터 크기·크롭·버튼 상태를 다시 비교한다.

캐릭터·로고는 `public/assets/design/`, 파일 선택은 `src/lib/assets.ts`에서 관리한다. 원본 바이트를 보존했고 SHA-256은 같은 폴더 `manifest.json`에 기록했다. 일반 양의 `drop` 내부 ID는 기존 모양 선택과 호환을 위해 유지하지만 화면 명칭은 ‘양’이다. 기본 양은 같은 Canvas에서 비율·기울기를 바꿔 반응한다. 이미지 내부가 국소적으로 늘어나는 물리 시뮬레이션은 아니다. 다른8개 모양의 기존 조작과 효과음은 유지한다.

D35 자산 반영 당시 원본 재조회는 실패했으나 D36에서는 사이드패널 원본 조회가 복구됐다. [최신 확인 범위](navigation-archive-2026-11-16.md)를 따른다. 음성·수면 파일 수령을 해당 기능의 완성으로 표시하지 않는다.

D36 보관함의 주간/목록 감정 표시는 임시 Unicode 이모지다. 디자이너가 별도 감정 PNG/SVG를 제공하면 `src/features/records/archiveModel.ts`의 표시 매핑과 해당 컴포넌트를 교체한다. API 선택 목록과는 별개다.

D37 추가: `socrates-with-toy.png`는 음성 화면에 연결했다. 발자국(결과 작은 실천), 마이크/음소거/채팅/중단, 메뉴 아이콘의 원본 SVG는 여전히 교체 대상이다. 컴포넌트 상태 전체를 하나의 PNG로 대체하지 않는다. [음성 원본 수치와 적용 범위](dialogue-voice-2026-11-16.md).
