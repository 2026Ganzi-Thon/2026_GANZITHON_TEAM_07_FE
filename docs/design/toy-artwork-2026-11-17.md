제공 PNG의 바이트·종횡비·투명도는 보존했다. `public/assets/design/manifest.json`에 원본 파일명과 SHA-256을 추가했다. 픽셀 정리·배경 제거·새 이미지 생성은 하지 않았다. 웹에서의 메시/색상층 변형은 런타임 출력이다.

메인 기본은 기존 양 스퀴시다. 종류별 기본은 슬랑이1·양·버터이며 모두 처음부터 선택 가능하다. 기존 절차적 모찌/식빵/별/진주/조약돌 등의 선택 UI는 제공된9개로 교체했다. 내부의 이전 절차적 윤곽 함수/물성 검사는 호환·회귀용으로 남아 있으나 새 모양 선택으로 노출하지 않는다.

추천 화면의 종류 후보는 선택만 바꾸며 CTA에서 체험으로 이동한다. 추천 그림은 현재 탭에서 해당 종류에 선택해 둔 모양을 사용하므로 체험에 들어가도 모양이 일치한다. 기록 상세는 저장된 추천 종류의 기본 그림을 사용한다. API에 개별 모양 필드/이력 저장을 임의 추가하지 않았다.

> 후속 D46에서 물성·기본 오디오·왁뿌볼 반복을 변경했다. 현재 값은 [D46](toy-depth-repeat-2026-11-17.md)을 우선한다. 아래 수치는 D45 당시 기록이다.

## 배치와 물성

논리 캔버스300×290/DPR 최대2, WebGL 메시24×16 구역은 D44와 같다. Canvas2D 대체/왁뿌볼 내부는 소프트웨어 출력 비용을 줄이기 위해12×8 구역을 사용한다. 새8개는 원본 알파80 초과 경계를 기준으로 폭250/높이164 안에 비율 유지해 맞췄다. 화면 중심은 논리좌표150/148이며 양은 D44의 기존 배치를 그대로 유지했다. 원본 여백을 파일에서 자른 것은 아니다.

| 재질 | 드래그 전달 계수 | 복원 전 대기 | 복원 곡선 시간 | 느낌 |
|---|---:|---:|---:|---|
| 슬랑이3종 | 0.64 | 160ms | 2,600ms | 넓은 접점 주변이 길게 끌려가며 천천히 모임 |
| 양 스퀴시 | 0.34 | 140ms | 1,600ms | 기존 양의 국소 눌림 유지 |
| 푸딩 스퀴시 | 0.38 | 180ms | 1,900ms | 옆으로 조금 더 퍼지고 납작해지는 탄성 |
| 만두 스퀴시 | 0.23 | 250ms | 2,500ms | 덜 늘어나고 눌린 자리가 느리게 복원 |
| 왁뿌볼 내부3종 | 0.30 | 100ms | 1,700ms | 껍질 제거 후 부드러운 눌림 |

위 시간은 개발 초기 촉감 조율값이며 기획/Figma의 확정 물리 규격이 아니다. 잔차 완화 시간은 조금 더 걸릴 수 있다. 그림을 축 전체로만 확대/축소하지 않고 접점 주변 메시를 다르게 움직인다. 화면 가장자리의 극단적인 드래그는 완만히 제한한다. 실제 압력 센서·부피 계산·뒷면·자유 회전·유체 해석 기능은 없다.

모든 그림은 자산별 알파 마스크로 보이는 몸체에서만 조작을 시작한다. 투명 여백·하트 위쪽 패인 부분·바닥 그림자는 대상에서 제외한다. 초기 로딩이 끝나기 전에는 버튼이 disabled/aria-busy 상태이며 이전 그림의 준비 상태를 다음 모양에 재사용하지 않는다. 모양별 로드 Promise와 마스크는 캐시한다.

## 왁뿌볼

원본 PNG가 껍질이다. 기존12개 분할 영역 중 접점에 가까운 남은2개씩 벗겨 총6회면 모두 제거된다. 조각은 원본 그림을 해당 영역으로 클립해 잠깐 떨어지며 사라진다. 남아 있는 껍질은 단단하게 유지하고6회 이후 내부의 눌림/드래그를 허용한다. 초기화하면 원본 껍질로 돌아간다.

내부 전용 원화는 제공되지 않았다. 원본 알파 윤곽에 같은 계열의 부드러운 그라데이션을 채운 절차적 색상층을 사용한다. 버터의 글자·하트의 광택 등은 껍질에만 남는다. 실제 껍질 두께·단면·완전한3D 파손을 구현했다고 해석하지 않는다.

## 코드와 출력

- `lib/toyArtwork.ts`: 파일 경로, 표시 사각형, 종류별 기본값.
- `toyArtworkLoader.ts`: 자산별 이미지/알파 캐시와 변형 좌표 입력 판정. D44 sheep 전용 로더를 대체한다.
- `artworkDeformation.ts`: 재질별 계수·국소 메시 변형·입력 역변환. D44 sheep 전용 변형을 공통화했다.
- `artworkRenderer.ts`: WebGL 텍스처 메시/국소 명암/그림자, Canvas2D 대체 메시. WebGL 미지원·컨텍스트 유실 대체 흐름 유지.
- `waxArtworkRenderer.ts`: Canvas2D 원본 껍질·클립 조각·절차적 내부. 내부 메시에도 같은 변형 함수를 사용한다.
- `physics.ts`, `useToyInteraction.ts`, `ToyCanvas.tsx`: 시간 기반 누름/복원, 포인터 소유·마스크·로딩 상태, 필요할 때만 프레임 요청.
- `Malangi`, `Records`: 결과/기록의 종류별 이미지. 비율이 다른 PNG도 기존 슬롯 안에 contain으로 표시한다.

줄인 모션은 지연 복원을 없애고 껍질 낙하를 생략한다. 화면 이탈/숨김·blur·키보드·종류 변경·초기화 처리는 유지한다. 기존 세 종류 효과음·음량·음소거 파일/정책은 변경하지 않았다. 로그인·수면·서체도 이번 변경 대상이 아니다.

검증 결과와 발견한 문제는 [QA](../qa.md)에 기록한다. 실제 휴대폰 GPU/발열/프레임률 및 소리·촉감 체감은 실기기 확인이 필요하다. 모양 선택은 현재 탭 메모리이며 운영 API 연동을 완료한 변경이 아니다.
