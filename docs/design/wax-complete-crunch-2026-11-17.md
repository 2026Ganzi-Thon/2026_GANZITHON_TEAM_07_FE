# D51 — 전체 파괴 후 조작과 거친 균열음

2026-11-17 · 로컬 검토. D50의 부분 파괴 중 안쪽 조작과 파열음 설계를 대체한다.

## 조작 기준

- 껍질이 하나라도 남아 있으면 눌림·늘림을 허용하지 않는다. 보이는 구멍을 누르거나 끌어도 다른 조각이 깨지거나 스퀴시 효과음이 나오지 않는다.
- 새로 누른 접점에 온전한 껍질이 있으면 그 조각 하나만 깨뜨린다. 마지막 조각이 깨지면 안쪽의 국소 눌림·늘림·복원과 기존 스퀴시 효과음을 사용할 수 있다.
- 전체 파괴 후 마지막 손 떼기부터 약1.78초 기다린 다음650ms 동안 껍질을 복원한다. 잡고 있는 동안에는 재생하지 않으며 복원 도중 다시 잡으면 멈춘다. 반복 횟수 제한은 없다.
- 투명한 조각 제외와 너무 작은 가장자리 영역의 재분할은 유지한다. 실제 누른 위치 대신 가장 가까운 미파괴 조각을 선택하지 않는다.
- `hasSoftContact`가 화면 변형과 소리의 공통 조건이다. 부분 상태의 드래그는 pull을 갱신하지 않고, 부분 상태에서 축적된 깊이를 마지막 파괴 시 이월하지 않는다.

## 소리

- 기존 음높이가 있는 정현파 성분을 제거하고 독립적으로 생성한 노이즈 입자를 사용한다. 낮고 거친 균열에 중고역 잔파열을 겹쳐 짧고 가벼운 팝보다 밀도 있는 빠그작 질감을 목표로 한다.
- 입력당20~34개 불규칙 입자, 전체 길이240~340ms. 개별 입자의 공격·감쇠, 전체 진폭·에너지 제한을 두며 매 입력에 다른 파형을 만든다.
- 기존 마스터 음량35%, 사용자 조작 후 활성화, 동시 음원4개 제한, 음소거·이탈 시 취소는 유지한다. 부분 구멍 입력은 무음이다.
- 참조 사이트의 기본 합성 구조를 읽어 소리 구성 방식을 비교했으나 녹음·Base64·소스 코드는 가져오지 않았다. 참조 소리와 동일하다는 보장은 없으며 최종 질감은 사용자 청취 확인이 필요하다.
- 기존 shell-1~3 파일은 출처 이력만 보존하고 실행 중 사용하지 않는다. 부드러운 누름/복원은 기존 표본을 유지한다.

## 검증 및 전달

최종 검사 결과는 [QA 기록](../qa.md)의 D51을 따른다. 자동 오디오 호출/파형 검증은 실제 스피커 청취 평가와 구분한다. 로그인·수면·음성 구현은 이번 수정 범위가 아니다. 커밋·푸시·PR·머지는 하지 않는다.
