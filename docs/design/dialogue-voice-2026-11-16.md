# D37 · 대화 입력, 음성, 메인 상호작용

> 이 문서는 당시 적용 기록이다. 첫 대화 진행/말풍선 간격/기록 상세/종료창의 현재 기준은 D39가 우선한다. 말풍선은 양의 실제 보이는 상단에 맞추고, 기록 동작은 카드 안으로 이동했다. 실제 브라우저 음성 서비스 연결 실패는 남아 있다. [현재 보완 내역](chat-home-records-2026-11-16.md).

확인일: 2026-11-16. 사용자 승인에 따른 프론트 보완이다. 노션·Figma 원본은 변경하지 않았다. 실제 AI·인증·DB 연결과 로그인 전체 흐름·수면 구현은 이번 작업 범위가 아니다.

## 대화 입력 수정

- 기존 시작 버튼은 표시 문장과 다른 상세 사건을 전송했고, 직접 입력은 제한된 사건 키워드 검사에 걸려 같은 추가 질문을 반복했다. 시작 문구와 실제 전송값을 일치시키고 시트·직접 입력·버튼·확정 음성의 전송 함수를 통일했다.
- OPEN은 사건 서술과 직전 사용자 발화를 함께 참고한다. 예를 들어 `출근길에 지하철을 놓쳤어`는 어떤 경로에서 보내도 감정 선택으로 이동한다. `친구가` 뒤 `연락을 안 받아`처럼 보충한 내용도 같은 상황으로 모은다.
- 자음만 입력하거나 상황이 모호하면 상황 확인 질문을 한다. 직전과 동일한 질문을 즉시 반복하지 않는다. 모름 누적·종료·위험 분기는 유지한다.
- 이 판단은 **로컬 정규식 어댑터**다. 모든 자유 발화를 이해하는 AI가 아니며 다른 단계의 의미 판단·맞춤 요약도 실제 서버로 교체해야 한다. 단순 문구 순환을 AI 이해 성능으로 해석하지 않는다.
- 한글 말풍선은 어절을 우선 보존하고 URL/긴 연속문자는 넘치지 않게 줄바꿈한다. 원본 본문15px/18px은 유지하고 입력란은 모바일 확대 방지를 위해16px이다.

## 음성 동작

마이크 버튼 → 사용자 권한/인식 시작 → 중간 전사문을 같은 대화 로그의 한 말풍선에 갱신 → 확정된 발화만 한 번 전송 → 답변 대기/읽기 → 다시 인식 순서다. 음성 화면에서도 현재 전사문을 볼 수 있다. 전사 속도는 브라우저가 보내는 이벤트 속도에 따른다.

- 채팅 버튼은 같은 세션의 텍스트 화면으로 전환한다. 음성 인식과 로그를 새로 만들지 않는다.
- 감정·강도 카드가 나오면 텍스트 화면으로 전환하고 인식을 잠시 멈춘다. 카드 완료 후 인식을 재개한다.
- 음소거는 마이크를 끄며 음성 중단은 텍스트 대화로 돌아간다. 두 경우 미확정 발화는 작성란에 보존한다. 이전에 타이핑한 초안도 유지한다.
- 종료 확인/설정창에서는 인식을 멈추고, 탭 숨김·화면 이탈에서는 인식과 읽기를 정지한다. 늦게 도착한 이전 인식 이벤트는 버린다.
- TTS는 브라우저의 한국어 음성을 우선 선택한다. 대화 설정에서 읽기를 끌 수 있고 읽는 동안 인식은 멈춘다. 소크라테스 전용 성우나 실시간 양방향 음성 AI는 아니다.
- 미지원·권한 거절·장치 없음·무음·연결 실패는 실제 오류와 재시도/텍스트 복귀로 처리한다. 동작하지 않는 환경에서 가짜 듣기 상태나 자막을 표시하지 않는다.

브라우저 `SpeechRecognition`은 지원이 제한되고 일부 구현은 음성을 브라우저 공급자 서버로 보낸다. 자체 백엔드 미연동이 오프라인·기기 내 처리라는 뜻은 아니다. [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [중간 결과 API](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/interimResults), 확인2026-11-16. 운영 전 공급자/음성 데이터 처리와 실기기 권한·한국어 인식·TTS를 별도 검증한다.

## 메인·메뉴·결과·MY

- 방문 중 짧은 초대 말풍선은 고정하고 재진입 시 4개 중 다른 문구를 고른다. 전체 새로고침 시 이전 선택은 저장하지 않는다.
- 대기 중 말랑이 그림만4.8초 주기로 작게 움직인다. 클릭 영역은 움직이지 않으며 조작·시트·탭 숨김·줄인 모션 설정에서는 정지한다.
- 우상단 메뉴는164px 폭, 항목 최소44px, 아이콘18px, 같은 왼쪽 기준선. 220ms 등장/사라짐과 reduced-motion 예외. 이는 메뉴가 캐릭터를 과하게 가린다는 피드백에 따른 웹 조정값이며 원본 측정값이 아니다.
- 결과의 실제 ACTION 값 앞에 발자국과 ‘작은 실천’을 표시한다. 없는 실천을 예시 문장으로 채우지 않는다. 발자국/메뉴 아이콘은 Lucide 근사이며 원본 SVG 교체 대상이다.
- MY는 직접 읽은 제목24px·프로필 최소147px/radius36·이름16px·항목48px/gap5를 유지한다. 어댑터가 주지 않는 이메일/생년월일/성별은 임의로 채우지 않는다. 도움 연결과 서비스 안내는 기존 웹 제공 기능으로 유지한다.
