# 수면 모드 화면 구현 — 2026-11-18 (feature/#11)

DF03 수면 모드와 OV06 설정 패널을 프론트 화면으로 구현했다. 기준은 팀 Figma `프로토타입` 페이지의 수면 프레임이다. 준비 화면은 `258:1373`, 설정 패널은 `71:349`, 설정 완료 문구는 `258:1142`, 실행 화면은 `71:328`이다. `디자인` 페이지의 컴포넌트도 참고했다. 타이머 `190:12853`, 화면 끄기 토글 `190:12922`, 사운드 버튼 `190:12927`·`190:12938`·`190:12949`·`190:12960`·`190:12971`이다. 사용자가 전달한 화면 캡처 3장으로 다시 대조했다. Figma 원본은 읽기만 했다.

## 경로와 동선

- 경로는 `/sleep`이다. 독립 경로는 9개에서 10개로 늘었다. 상담·기록 데이터를 쓰지 않으므로 체험 계정 진입(`RequirePreview`)을 요구하지 않는다.
- 메인 메뉴의 `수면 모드`는 기존 "준비 중" 모달 대신 `/sleep`으로 이동한다(`AppMenu`).
- 준비 화면은 뒤로가기, 제목, 톱니 버튼, 수면 양, 설정 요약, `수면 모드 실행`, 하단 패널 손잡이로 구성한다.
- 하단 손잡이는 **위로 끌어올려야만** 설정 패널이 열린다(사용자 요청). 끄는 동안 손잡이가 손가락을 따라 늘어나고, 64px 이상 끌어올린 뒤 놓으면 열린다. 그보다 짧으면 제자리로 돌아간다. 한 번 탭해서는 열리지 않는다.
- 키보드 사용자는 손잡이에서 Enter/Space로 열 수 있다. 탭으로 여는 대안은 상단 톱니 버튼이다. 톱니가 MY/설정으로 가는 대신 수면 설정을 여는 것은 이번 구현의 가정이다.
- 실행 화면에서는 뒤로가기와 제목을 감추고 톱니와 `수면 모드 종료`만 둔다(Figma `71:328` 기준). 남은 시간은 화면에 표시하지 않고 보조기술용 텍스트로만 제공한다.

## 설정 패널

| 항목 | 동작 |
|---|---|
| 수면 사운드 | 백색소음·빗소리·자연음·말랑이 ASMR·수면 유도 음악. 선택 순서대로 최대 2개. 3번째를 누르면 선택하지 않고 "사운드는 최대 2개까지 고를 수 있어요."를 표시한다. 동시에 패널 전체가 좌우 최대 4px로 0.24초간 가볍게 움직인다. 거절할 때마다 다시 움직이고, 줄인 모션 설정에서는 움직임 없이 문구만 표시한다 |
| 수면 유도 음악 | 음원 미수령이라 `aria-disabled`와 "준비 중"을 표시하고 선택하지 않는다 |
| 타이머 | 15분/30분/1시간/2시간. 실행 중에 바꾸면 그 시점부터 다시 센다 |
| 무드등 밝기 | 0~100%, 10단위. 양 그림의 밝기와 뒤쪽 빛번짐으로 표현 |
| 타이머 종료 후 화면 끄기 | 켜면 타이머가 끝날 때 검은 화면으로 덮는다. 웹은 기기 화면을 실제로 끌 수 없다. 화면을 누르면 준비 화면으로 돌아간다 |

- 기본값은 빗소리, 30분, 40%, 화면 끄기 켜짐이다. Figma 준비 화면 문구 "빗소리 · 30분 타이머로 설정했어요"에 맞췄다.
- 요약 문구는 "A 및 B · 2시간 타이머로 설정했어요" 형식이다. 사운드가 없으면 "사운드 없이"로 표시한다.
- 설정은 현재 탭 메모리(reducer)에만 있다. 서버나 브라우저 저장소에 남기지 않는다. 새로고침하면 기본값으로 돌아간다.

## 오디오 정책

- 재생은 `수면 모드 실행`을 누를 때만 시작한다(사용자 활성화). 종료 버튼, 페이지 이탈, `pagehide`, 탭 숨김(`visibilitychange`)에서 멈추고 자동으로 다시 시작하지 않는다.
- 이 정책 때문에 휴대폰을 잠그면 소리가 멈춘다. 잠금 중 재생이 필요하면 AGENTS.md의 "숨김 시 정지" 원칙에 대한 별도 결정이 필요하다.
- 타이머가 끝나면 4초 동안 서서히 줄인 뒤 오디오 그래프를 정리한다.

> **2026-11-19 갱신:** 팀이 제공한 음원 3개(빗소리·자연소리·파도 소리)로 교체했다. 말랑이 ASMR은 여전히 조작 효과음 재사용(임시)이고, 수면 유도 음악은 음원 대기다.

- 제공 음원은 실행 버튼을 누른 뒤 처음 선택될 때 내려받는다. 무작위 위치부터 반복 재생하고, 1.5초 동안 서서히 키운다.
- 음원을 내려받거나 디코딩하지 못하면 이전의 브라우저 생성음으로 대신 재생하고 "일부 수면 음원을 불러오지 못해 대체 소리로 재생하고 있어요"를 표시한다.
- 반복 이음새의 끊김 여부는 실제 청취로 확인하지 않았다.

음량(마스터 35%, 제공 음원 80%)과 사운드별 레벨은 임시값이다. 실제 휴대폰·이어폰 청취로 정하지 않았다.

Web Audio가 없는 브라우저에서는 "무드등과 타이머만 동작해요" 안내를 표시한다. 재생 중인 것처럼 꾸미지 않는다.

## 재사용한 공통 컴포넌트

- `Page`: 헤더(뒤로가기·제목·우측 action)와 본문 틀. 어두운 배경은 `className`으로 덮었다.
- `BottomSheet`: 설정 패널. 드래그 닫기, 포커스 가두기, Escape, 배경 클릭을 그대로 쓴다. 선택 속성 `closeLabel`과 `className`을 추가했고, 기본값은 기존 대화 시트와 같다.
- `IconButton`: 톱니 버튼.
- `AppMenu`: 수면 모드 항목에서 화면으로 이동.
- `DESIGN_ASSETS`: `sleepSticker`를 추가했다.

## 자산

- 수면 양 그림은 사용자가 전달한 `포근한 잠꾸러기 양 스티커 3.svg`(Figma 이미지 371×247, 따뜻한 drop shadow 필터)에서 왔다.
- 이 SVG(2MB, base64 PNG 내장)를 그대로 쓰면 첫 진입 때 그림이 늦게 나타났다. 그래서 내장 PNG 바이트를 변경 없이 꺼내 `lamb-sleep-sticker.png`(1536×1024 RGBA)로 저장했다. 필터는 CSS `drop-shadow(2px 4px 26px #ffe0c540)`로 근사했다.
- 해시와 출처는 `public/assets/design/manifest.json`과 [자산 문서](../assets.md)에 기록했다.
- 기존 `lamb-sleep.png`(419×295)는 보관만 한다. 파일 크기 1.5MB는 다른 원본 PNG와 같은 원본 보존 방식이다. 모바일 최적화본 제작 여부는 별도로 결정한다.
