# D44 — 양 스퀴시 자산과 국소 눌림

2026-11-17 로컬 검토. 제공된9개 말랑이 중 양 스퀴시1개를 먼저 적용한다. PR·원격 Git은 변경하지 않는다.

## 자산과 적용 위치

- 원본 `양 스퀴시.png` → `public/assets/design/sheep-squishy.png`, 1536×1024 RGBA, 825,571바이트. 원본 바이트·투명도·여백 보존. SHA-256은 같은 폴더의 manifest에 기록했다.
- 메인 기본 조작, 모양 선택의 양 썸네일, 공통 `Malangi`를 사용하는 추천/기록 상세 그림을 교체했다. 기존 `lamb.png`는 이력용으로 남기되 현재 대표 그림은 새 파일이다.
- 신규 프론트 체험의 기본 종류는 SQUISHY, 모양은 `sheep`이다. 서버/현재 선택값과 명시적 종류 URL은 우선한다. 추천 감정 대응표는 수정하지 않았다.
- SLANGI의 기존 `drop`은 ‘양’에서 ‘물방울’로 표시를 바로잡고 절차적 Canvas 그림을 사용한다. 기존 스퀴시 모찌/식빵/별은 유지하므로 현재 모양 선택지는10개다. 새로 수령한 슬랑이3종·왁뿌볼3종·푸딩/만두 스퀴시의 적용은 다음 범위다.
- 결과/기록의 공통 그림은 아직 종류별 자산 전체에 연결하지 않았다. 양 교체를 세 종류의 최종 디자인 완성으로 해석하지 않는다. 로고·석상·음성 전신·수면 양과 로그인/수면 동작은 그대로다.

## 표현과 입력

제공 PNG를24×16 구역(425정점·768삼각형)의 작은 메시 위에 표시한다. 접점 가까운 영역이 더 눌리고 드래그 방향으로 조금 끌려가며, 나머지 형태는 최대한 유지한다. 접점 명암과 바닥 그림자를 더한2.5D 표현이다. 뒷면·자유 회전·실제 부피나 유체 물리 계산은 없다.

- 논리 캔버스300×290, 그림 영역 x0/y45/w300/h200. 표시 배율은 기존 반응형 레이아웃을 따르고 실제 그리기 해상도는 DPR2까지다.
- 누르는 시간에 따라 눌림이 커지되 최대0.9로 제한한다. 드래그 입력은 논리 좌표 x±100/y±75 이내이며 그림 변위는 국소 가중치를 추가 적용한다. 기기의 실제 압력 센서를 읽는 기능이 아니다.
- 입력 값과 화면 변형은 시간 기반 완화로 연결한다. 손을 떼면140ms 후부터1,600ms 동안 완화 곡선으로 복원하고 작은 잔차까지 정리한 뒤 그리기를 멈춘다. 양만 이 값을 사용하며 다른 임시 재질의 기존 대기/복원 시간은 유지한다.
- 줄인 모션 설정에서는 지연 복원을 없앤다. 처음 모양으로·종류 변경·포인터 해제·화면 숨김의 기존 처리와 키보드 입력을 유지한다.
- 192×128 알파 마스크와 변형 역변환으로 보이는 몸체 안에서만 조작을 시작한다. 투명 여백·바닥 그림자 누름은 활성화/효과음을 만들지 않는다. 드래그가 몸체 밖으로 이어지는 것은 허용한다.
- 첫 이미지와 알파 마스크가 준비되기 전에는 조작 버튼을 `disabled`/`aria-busy`로 둔다. 로딩 중 버튼이 활성화된 것처럼 보이지만 첫 입력만 무시되는 경합을 막는다. 같은 이미지 로드 Promise를 입력과 출력에서 공유한다.

## 출력과 코드 경계

| 파일 | 책임 |
|---|---|
| `sheepDeformation.ts` | 국소 좌표 변형·입력 판정용 역변환 |
| `sheepArtwork.ts` | 이미지 캐시·알파 마스크·몸체 입력 판정 |
| `sheepRenderer.ts` | WebGL 텍스처 메시·국소 명암·바닥 그림자, Canvas2D 삼각형 대체 출력 |
| `physics.ts` | 누름/드래그/복원 값·시간 완화 |
| `ToyCanvas.tsx` | 이미지 로드·출력 수명·이벤트·필요할 때만 프레임 요청 |
| `useToyInteraction.ts` | 기존 포인터/키보드/효과음에 양 입력 판정 연결 |

WebGL 미지원은 Canvas2D 메시로 대체한다. 출력 생성 실패나 WebGL 컨텍스트 유실도 새 캔버스로 교체해 Canvas2D를 사용한다. Canvas 대체 화면은 같은 변형을 사용하지만 별도 국소 명암 효과는 생략한다. 삼각형 경계의 틈은 클립 영역을 조금 겹쳐 그려 줄였다. 이미지 자체를 재생성하거나 파일로 수정한 처리는 없다. 이미지와 Canvas 모두 사용 불가능한 환경까지 조작 성공을 보장하지 않는다.

## 효과음과 후속 범위

기존 SQUISHY의 foam 샘플과 음소거·음량·화면 이탈 정지 정책을 유지했다. 새 음원 다운로드/레퍼런스 음원 복사/오디오 파일 수정은 없다. 기존 샘플의 출처는 [자산 기록](../assets.md)에 있다.

다음에는 양의 촉감 피드백을 확인한 뒤 다른8개 그림을 재질별 조작에 연결한다. 왁뿌볼의 껍질/내부 자산 분리, 슬랑이의 큰 늘림 등은 이번 구현을 그대로 적용할 수 있다고 확정하지 않는다. 실제 휴대폰 GPU/발열/음향 체감은 실기기 검수가 필요하다. 이번 브라우저 검증 범위는 [QA](../qa.md)를 따른다.
