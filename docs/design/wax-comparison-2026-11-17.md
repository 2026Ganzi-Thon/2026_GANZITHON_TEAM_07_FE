# D52·D53 — 버터 파편 / 하트 구김·벗겨짐 비교

2026-11-17 · 두 동작을 비교하기 위한 로컬 구현. 최종 공통 사양은 아직 선택하지 않았다. D51의 전체 파괴 규칙은 버터·구름에 적용하고, 하트는 명시적인 비교안으로 분리한다.

## 동작

| 모양 | 누를 때 | 손을 뗄 때 | 부드러운 안쪽 |
| --- | --- | --- | --- |
| 버터 | 접점의 한 조각 안에서 작은 삼각 파편들이 접혔다 비틀리며 떨어짐 | 파괴 상태 유지 | 전부 깨뜨린 뒤에만 눌림/늘림 허용. 마지막 손 떼기 후 약1.78초 대기+650ms 껍질 복원 |
| 하트 | 반경76논리px 안의 면들이 구겨짐. 350ms 이후 반경54논리px 안의 일부 면이 점차 들리고 벗겨져 내부 색상이 드러남 | 소리 중단, 약1초 안에 원래 PNG로 복귀 | 파괴 완료/안쪽 조작 단계 없음. 반복해서 같은 자리를 누를 수 있음 |
| 구름 | 기존 접점 한 조각 파괴 유지 | 파괴 상태 유지 | D51 전체 파괴 후 조작/복원 유지 |

- 버터의 시각적 파편은 해당 조각의 내부를 분할한다. 작은 파편 수만큼 파괴 횟수를 증가시키거나, 깨진 곳을 눌렀을 때 이웃 조각을 대신 깨뜨리지 않는다.
- 하트는 화면에 보이는 압축/구김이며 실제3D 모델·회전·체적 물리가 아니다. 원본 이미지와 배치를 유지한다. 멀리 떨어진 영역의 구김은0이다.
- `ToyModel.waxMode`로 두 상태를 구분한다. 일반 모델 기본값은 `break`, 하트의 UI 선택 시 `crumple`을 명시한다. 초기화에서도 모드를 보존한다.
- 줄인 모션: 버터의 날아가는 파편은 생략, 하트는 정적인 눌림 표시 후 즉시 복귀. 음소거·초점 이탈·종류 변경 시 기존 취소 정책 유지.
- 파편 이미지는 처음부터 전부 만들지 않고 실제 접촉한 영역만 생성해 재사용한다. 원본 PNG도 작은 화면용 텍스처에 한 번 그려두고 조각에 재사용해 선택 직후와 첫 조작의 렌더링 부담을 줄인다.

## D53 하트 길게 누르기

- 벗겨짐은 약1.75초까지 증가하며 접점 주변으로 제한한다. 일부 면은 남겨 전체 껍질이 한꺼번에 사라지지 않는다. 길게 누르는 동안 작은 잔조각이 떨어지며 반복된다. 영구 파괴/안쪽 조작 단계는 추가하지 않는다.
- 파열음 표본을520ms 간격으로 이어 재생한다. 기존 동시 재생4개 제한을 유지한다. 손 떼기·pointer cancel·초점 이탈·종류 변경·초기화·음소거·음량0·dispose에서 반복 예약/재생을 정리한다. 본체 밖으로 드래그하면 추가 파열음을 내지 않는다.
- 줄인 모션에서는 날리는 잔조각을 생략하고 눌림/벗겨짐 상태를 표시하며 손을 떼면 즉시 복귀한다. 버터·구름의 동작은 변경하지 않았다.

## 추출 음원 — 로컬 전용

- 제공된2026-11-17 화면 녹화에서0.97~1.72초,2.42~3.29초,3.85~4.81초를 추출했다. 44.1kHz/스테레오/PCM16, 앞뒤3ms 페이드만 적용하고 원래 속도와 진폭을 보존했다.
- 파일은 Git 제외 경로 `artifacts/wax-reference/crunch-1.wav`~`crunch-3.wav` 및 같은 폴더의 출처/가공 manifest다. `public`에 복사하지 않으며 `dist`에도 포함하지 않는다.
- 로컬 `.env.local`의 `VITE_LOCAL_WAX_REFERENCE=true`가 켜져 있고 loopback에서 접속할 때만 요청한다. Vite 개발/미리보기 미들웨어가 `/__local-wax__/crunch-[123].wav`의 고정 파일만 로컬 요청에 제공한다. 빌드용 정적 자산 경로가 아니다.
- 버터·하트에서만 사용한다. 구름은 기존 독립 합성음을 사용한다. 추출 표본이 준비되지 않았거나 없으면 독립 합성음으로 동작한다. 사용자 동작 전에 소리를 재생하지 않고, 음소거/이탈 시 예약과 재생을 취소한다.
- 녹화본 추출·로컬 비교 사용과 공개 재사용 허가는 별개다. 공개 사용 조건은 미확인이다. 추출 음원은 PR에 포함하지 않는다. 공개 배포에서 이 음원을 사용하려면 별도 사용 조건 확인이 필요하다. 버터/하트의 서로 다른 조작 방식은 현재 비교 구현으로 유지한다. 미들웨어는 로컬 편의를 위한 코드이며 정식 오디오 API가 아니다.
