# D46 — 국소 깊이·재질 복원·왁뿌볼 반복

2026-11-17. 구현 검토 기록. D45의 이미지 전체 퍼짐과6회 파괴 종료 방식을 대체한다. 제공 PNG9종과 음원9개는 원본 그대로 사용한다. 로그인·수면·서체·API는 변경하지 않았다. 검증 결과는 [QA](../qa.md)에 기록한다.

## 접점과 복원

누른 위치에 가상의 오목한 높이장과 얕은 주변 융기를 만든다. 높이장의 경사를 법선으로 계산해 눌린 면의 명암이 바뀐다. 원본 그림에 이미 그려진 조명은 유지되므로 실제3D 재구성/회전과는 다르다. 메시 자체의 전체 퍼짐·납작해짐은 제거하고 접점 주변의 작은 위치 변형을 사용한다. 손가락 이동8논리px까지는 드래그 변형을 만들지 않는다. 이후 이동에서만 재질별 계수로 당긴다. 실제 압력 센서 대신 누르고 있는 시간으로 깊이를 늘린다.

| 재질 | 접점 반경(논리px) | 당김 계수 | 복원 대기 | 복원 곡선 시간 |
|---|---:|---:|---:|---:|
| 슬랑이3종 | 38 | 0.55 | 100ms | 2,600ms |
| 양 | 30 | 0.17 | 90ms | 1,800ms |
| 푸딩 | 32 | 0.22 | 50ms | 1,500ms |
| 만두 | 29 | 0.12 | 180ms | 2,300ms |
| 왁뿌볼 내부3종 | 31 | 0.19 | 80ms | 1,700ms |

양·만두·슬랑이·왁뿌볼 내부는 완만하게 멈추는 감쇠 복원, 푸딩은 작은 반동을 포함한 감쇠 복원이다. 프레임간 완화 때문에 실제 정지까지 약간 더 걸릴 수 있다. 이 값은 웹 촉감 조율값이며 기획/Figma의 물리 규격이 아니다. 이미지의 지수 완화에는 실제 경과 시간을 사용한다. 예전 절차적 도형 스프링의50ms 적분 제한을 이미지에도 적용하면 저프레임 환경에서 복원이 길어지므로 두 계산을 분리했다. 이미지가 쓰지 않는 윤곽 노드는 RAF 정지 여부를 지연시키지 않는다.

WebGL은24×16 메시와 fragment 명암을 사용한다. Canvas2D 대체와 왁뿌볼 내부는12×8 메시/96×96 조명장을 사용하며 원본 알파 내부에만 조명을 합성한다. 입력 역변환·이미지 로드 대기·투명 영역 제외·극단적인 드래그 제한은 유지한다. 줄인 모션에서는 손을 떼면 즉시 정지 자세로 돌아온다.

## 왁뿌볼 반복

고정6회 제한 대신 남은 껍질 영역을 판단한다. 가까운 영역1개를 깨고85논리px 안에 이웃이 있으면 함께 깨므로 접점에 따라 한 번에1~2개가 깨진다. 현재12개 영역은 표현을 위한 분할값이다. 남은 껍질이 있으면 단단한 상태를 유지하며 모두 깨지면 부드러운 내부를 만질 수 있다.

모두 깨진 뒤 마지막 손 떼기부터1,780ms 후650ms 동안 껍질이 서서히 돌아온다. 누르고 있는 동안 자동 복원하지 않는다. 복원 도중 다시 누르면 현재 껍질 표시 비율에서 멈추고, 다시 손을 떼면 대기 후 이어진다. 복원 완료 시 원본 껍질로 다시 깨뜨릴 수 있다. 횟수/회차 상한은 없고 초기화 버튼도 유지한다. 껍질 복원 자체에는 파괴 소리를 재생하지 않는다.

`hasShell()`과 남은 영역이 재질 상태의 기준이다. `cracks`는 조작 횟수 표시/검증용이며 완료 임계값이 아니다. `shellRestore`, `shellRestoreBase`, `shellCycles`는 재생 상태다. `nextToyWakeAt()`은 RAF가 멈춘 대기 구간에도 복원이 시작되게 하며 화면 숨김·이탈에서는 그리기를 중지한다. 재진입 시 경과 시간에 맞춘다.

내부는 별도 원화 없이 같은 알파 윤곽에 색을 채운 절차적 층이다. 원본 버터 글자/껍질 광택은 내부층에 복사하지 않는다.

## 오디오

효과음 기본 켜짐, 음량35%. 화면을 열기만 했을 때 오디오 컨텍스트나 음원 요청을 만들지 않는다. 실제 말랑이 누르기/키보드 조작 또는 효과음 켜기로 활성화한다. 기존 PCM 샘플을 로드하고 오디오가 활성화되는 동안 첫 입력을 오디오 시간축에 즉시 예약한다. 파일이 아직 준비되지 않으면 기존 짧은 합성 효과를 사용하며 이후 입력부터 준비된 샘플을 사용한다. 비동기 완료 후 예전 입력을 다시 호출하지 않는다.

음소거 선택은 현재 탭에서 모양/종류 변경 후에도 유지한다. 음량0·음소거·초기화·화면 이탈·탭 숨김에서 소리를 멈추고 대기 중인 첫 재생도 무효화한다. Web Audio 미지원은 사용 불가 상태로 표시하며 말랑이 조작은 유지한다. 첫 입력 정책/실제 기기 스피커·블루투스 출력 검수와 자동화 검증을 구분한다.

## 추천 배경 — 원본 확인

[Figma 말랑이 추천71:407](https://www.figma.com/design/vmbKI4ltraNNxZSlhmg27N/?node-id=71-407)에서 프레임402×874, 채우기 **단색 #FFF9F2 /100%**를 사이드패널로 읽었다. 전용 MCP의 재인증 오류와 별개로 원본 속성 조회에 성공했고 원본은 변경하지 않았다.

기존 구현의 회색→아이보리 그라데이션을 해당 단색으로 교체한다. 상단 아이콘은 밝은 배경에서 읽히는 기존 중성색 토큰을 사용한다. 이 아이콘 색은 이번에 원본 숫자를 재측정한 값이라고 주장하지 않는다. 카드/이미지 슬롯/기록 링크의 높이와 긴 내용 스크롤 규칙은 유지한다.

## 변경 위치와 인계

- `artworkDeformation.ts`: 재질 계수·위치 변형·조명 식·복원 곡선.
- `artworkRenderer.ts`: WebGL/Canvas 명암과 메시. 두 경로 모두 검수한다.
- `physics.ts`, `ToyCanvas.tsx`, `waxArtworkRenderer.ts`: 남은 영역·자동 복원·깨우기·껍질 합성.
- `useToyInteraction.ts`: 껍질 존재 기준 입력/소리 선택, 고정 횟수 안내 제거.
- `audio.ts`: 기본 ON·첫 조작 활성화·대기 재생 취소.
- `Records.module.css`: 추천 배경/상단 아이콘 대비.

추가 라이브러리·원본 이미지 편집·레퍼런스 음원 복사는 없다. 운영 인증·AI·기록 DB 연동 완료를 뜻하지 않는다.


## D47 후속 조율 — 복원음·그림자

스퀴시 양/푸딩/만두에 정상 손 떼기 또는 키보드 완료 후 복원음을1회 연결한다. 재질 대기90/50/180ms에 맞추며, 기존 foam 샘플을 최대0.42초/작은 볼륨/완만한 시작/재생 속도1→1.18로 사용한다. 원본 음원 파일 수정이나 새 외부 음원 추가는 없다. 눌림 시간에 따라 강도가 달라진다. 취소·blur·초기화는 무음이며 새 입력·음소거·음량0·이탈은 대기 재생도 취소한다. 다른 종류에는 새 복원음을 추가하지 않는다.

표면 밝기 식의 대비0.85→0.40, 중앙 어둠0.10→0.045, 범위0.68~1.22→0.85~1.10으로 조율했다. 바닥 그림자는 WebGL0.11+깊이×0.035에서0.055+깊이×0.015, Canvas알파36/255에서18/255로 낮췄다. 원화 자체의 그림자와 접점의 위치 변형/복원 시간은 유지한다.
