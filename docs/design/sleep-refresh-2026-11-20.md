# 수면모드 참고 화면·음원 반영 — 2026-11-20

후속 배경 보정은 [로그인·스플래시/수면 배경](login-splash-entry-2026-11-20.md)의 중성 차콜 정지점을 우선한다. 기본 real 모드의 직접 수면 진입도 인증을 확인한다.

## 현재 동작

- 이번 범위는 수면 UI/음원과 채팅 상단 상태 문구 제거다. 로그인·서버 상담·결과 문장·백엔드를 변경하지 않는다. 이전 ‘수면 수정 제외’ 범위 이후 승인된 수면 후속 작업이다.
- 준비 화면은 제공 ‘수면모드 설정.png’의 중앙 양, 작은 설정 요약, 동동체 실행 버튼과 하단 손잡이를 따른다. 브라우저가 담당하는 시계/배터리 상태바는 앱에 복제하지 않는다.
- 상단 메뉴는 메인과 같은 AppMenu를 사용한다. MY에서 뒤로 가면 수면 화면으로 돌아오며, 감정 기록은 공통 ChatEntrySheet를 연다. 수면 사운드·타이머·밝기·화면 끄기는 하단 패널에서 설정한다.
- SleepPanel은 실제 설정 내용이 포함된 한 장의 패널이다. 닫힌 상태에서도 내용을 렌더링하고 프레임 밖으로 내려둬, 위로 끄는 동안 빈 검정 영역 대신 설정 내용이 손잡이와 함께 올라온다. 64px 이상 드래그하면 열리며 짧은 드래그는 닫힌 위치로 돌아간다. 손잡이 클릭/키보드로도 열고 Escape·닫기·배경 클릭·아래로 드래그로 닫는다. 접힌 내용과 패널 뒤 화면은 inert 처리한다.
- 실행 시 어두운 배경(#1D1C1B/#27282C), 상단/요약/손잡이의 투명도, 타이머 표시를 약 0.7~0.85초에 전환한다. 종료는 역방향이다. 양을 다른 이미지로 교체하거나 화면 전체를 검정색으로 덮는 방식이 아니다. 모션 감소 설정에서는 전환/호흡을 생략한다.
- 타이머는 설정 시각부터 `30:00` 등의 분:초로 표시한다(2시간은 `120:00`). 종료시각과 현재 시각 차이로 계산한다. 매초 스크린리더 공지를 반복하지 않는다. 타이머 종료 후 화면 끄기는 앱 내부 검정 덮개이며 휴대폰 시스템 잠금이 아니다.
- 기본 빗소리·30분·밝기40%·화면 끄기 ON, 최대 2종 선택을 유지한다. 탭 숨김·페이지 이탈 시 재생 종료 정책도 유지한다. OS 잠금/백그라운드 지속 재생을 보장하지 않는다.

## 음원

- ‘백색소음’ 표시를 ‘파도소리’로 바꾸고 제공 PNG 아이콘을 사용한다. 내부 WHITE 키는 기존 계약 호환을 위해 유지한다.
- 제공 파도·빗소리·자연소리 MP3는 기존 수록 파일과 SHA256이 같다. 이번 제공본을 원본 그대로 복사해 확인했다.
- 수면 유도 음악 준비 중 표시를 제거하고 두 곡을 1→2→1 순서로 반복한다. 긴 음악은 HTMLAudioElement와 MediaElementAudioSourceNode로 스트리밍해 두 곡을 모두 PCM으로 펼쳐 메모리에 담지 않는다. 자연음은 기존 AudioBuffer 루프 방식, 말랑이 ASMR은 기존 표본을 유지한다.
- MP3 파일 자체는 편집하지 않았다. 재생 시 곡 끝 약 1초/시작 1.5초 페이드와 곡별 게인을 적용한다. 원음 분석에서 1번 평균 -17.8dB/피크 -4.0dB, 2번 평균 -27.2dB/피크 -12.9dB로 차이가 있어 게인 .8/2.25로 맞췄다. 마스터 게인 .35와 기존 동시 2종 제한을 유지한다.
- 수동 종료는 0.6초 페이드, 타이머 종료는 기존 4초 페이드다. 재실행은 이전 종료 예약을 취소하며 해제한 음악의 ended 콜백이 다음 곡을 다시 시작하지 않게 한다. 파일 실패/재생 거부는 오류로 표시한다.
- 원본 영상은 로컬 분석에만 사용하며 배포 자산에 포함하지 않는다. 제공 음원의 파일 대응과 해시는 public/assets/audio/LICENSES.md에 기록한다.

## 채팅

real/mock 대화 상단의 응답 대기·단계·마지막 점수 안내 문구를 제거했다. 끝내기와 메시지 영역의 응답 준비 표시/실제 오류 안내는 유지한다. 대화 전송·종료 로직은 그대로다.

PR·병합·배포 없이 로컬 확인 단계다. 검증 결과와 제한은 docs/qa.md 최신 항목을 따른다.

Chromium에서 제공 음원 출력과 두 음악의 native ended 순환을 확인했다. Windows용 Playwright WebKit에는 Web Audio가 없어 실제 음원 검사를 할 수 없었으며, 화면/타이머/메뉴/지원 불가 안내는 검사했다. iPhone Safari 실기기 재생은 별도 확인 대상이다.
