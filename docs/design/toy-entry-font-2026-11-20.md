# 말랑이 진입 경로 통일·Cafe24 동동체

## 기준과 범위

- 최초 기준: main `27ba0b4`. 최종 통합 기준: PR #14 병합 후 main `33a16ab` (2026-11-20).
- 메인에서만 최신 체험 UI를 사용하고 추천·기록 상세는 별도 `/malangi`의 옛 UI를 사용하던 문제를 수정했다. 캐시 문제나 조작 엔진 롤백이 아니었다.
- PR #14의 이메일 인증·API 변경과 수면 설정 피드백을 보존해 로컬에 통합했다. 로그인 로직·수면 상태/음원·말랑이 물성과 음원은 별도 수정하지 않았다. 수면 설정 CSS의 표시 서체만 이번 UI 범위에 포함한다. 음성 실험은 기존 별도 백업에 유지하며 다시 적용하지 않았다.

## UI와 이동

- `ToyChrome.tsx`/CSS에서 상단 종류 선택·음소거·4개 메뉴와 하단 중앙 `체험 마치기`를 공유한다. 두 화면의 상단 높이는 일반80px+safe area, 짧은 가로 화면58px다. 컨트롤은44px이며 메뉴 배경은 기존 반투명 유리 효과다.
- 독립 체험의 하단 메뉴, `처음 모양으로`, 상단 홈 고정 화살표/설정 톱니를 제거했다. 기존 URL은 유지해 저장된 링크를 깨뜨리지 않는다.
- 추천 CTA는 선택 종류와 출발 결과를 전달한다. 결과로 돌아오면 후보 선택은 유지하지만 저장된 추천 감정/종류는 변경하지 않는다.
- 기록 CTA는 해당 기록의 추천 종류로 이동하고 기록 경로·조회 상태를 출발 정보로 전달한다.
- 종류 변경 및 설정 왕복은 `location.state`의 출발 정보를 유지한다. 종료 시 출발 추천/기록 화면을 복원한다. 출발 정보 없는 직접 진입은 메인으로 돌아간다. 외부 URL은 복귀 대상으로 허용하지 않는다.
- 종료·대화 진입은 기존 `interaction.release()`와 `audio.stop()`을 호출한다. 화면 이탈 정리는 기존 hook/provider를 유지한다.

## 서체

제공 OTF를 변환 없이 `public/fonts/Cafe24DongdongRegular.otf`에 넣었다. `--font-display`는 Cafe24Dongdong → Pretendard 순서다. 기존 꾹꾹체 @font-face·토큰·배포 파일은 제거했다. 과거 커밋 이력은 재작성하지 않는다.

| 영역 | 적용 | 기존 크기 유지 |
| --- | --- | --- |
| 상단 메뉴 3개 항목 | 동동체400 | 16px |
| 설정/MY 메뉴 행 | 동동체400 | 기존 15/16px |
| MY 페이지 메뉴 항목 | 동동체400 | 16px / 줄높이20px |
| 추천 카드 전체: 제목·종류·조작 안내 | 동동체400 | 기존 제목20px, 종류/안내12px 유지 |
| 추천 남은 문장 | Pretendard, 라벨500/본문600 | 기존 크기 유지 |
| 수면 실행·종료 버튼 | 동동체400 | 17px |
| 수면 설정 구역 제목 | 동동체400 | 15px |
| 수면 사운드 / 타이머 선택 | 동동체400 | 13px(좁은 화면12px) / 14px |
| 설명·수치·본문·입력·일반 헤더 | Pretendard | 기존 크기 유지 |

동동체는 Regular 파일이므로 합성 볼드를 만들지 않는다. 선택 상태는 기존 배경·테두리와 aria-pressed로 구분한다. 원본 파일 SHA-256 및 공식 웹폰트/임베딩 허용 안내는 [자산 기록](../assets.md)을 따른다.

## 원본 확인 한계와 통합 주의

후속 로그인 배치는 새 PNG의 고유 비율을 유지하는 contain 영역으로 변경했다. 원본 이미지 밖의 내용을 새로 만들거나 오른쪽으로 이동·확대하지 않는다. 가입 필드는 이메일→비밀번호→닉네임 순이다. 음성 패널에는 반투명 배경, 가장자리 반사, backdrop blur를 적용하고 미지원 환경은 단색 배경으로 대체한다. 굴절처럼 보이는 가장자리 효과는 시각적 근사이며 실제 광학 왜곡은 아니다. 기술 참고: [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter). 최신 Figma 재조회는 oauth_token_invalid_grant로 실패했다.

이번 Figma 사이드패널 조회는 도구 초기화의 kernel assets 경로 오류(os error3)로 실패했다. 직전 플러그인 조회도 토큰 재인증 오류였다. 최신 MY·수면 설정·추천 텍스트의 수치를 새로 측정한 결과가 아니다. 사용자 승인에 따라 제공 서체를 적용하고 기존 크기·간격을 유지했으며, 원본 연결 복구 후 요소별 서체 적용 범위·크기·줄높이를 다시 비교해야 한다.

과거 문서의 독립 체험 초기화 유지·꾹꾹체 사용 설명보다 이 문서를 우선한다. PR #14 통합 시 인증 상태 문서는 최신 내용을 유지하고 이 문서의 화면/서체 변경을 함께 반영했다. 수면 컴포넌트의 팀원 동작 변경을 보존했다.

검증 결과와 미검증 범위는 [QA 기록](../qa.md)에 기록한다. 실제 휴대폰 검증과 공개 배포는 별도다.

통합에서 함께 수정된 파일은 README·인수인계·자산/현황 문서와 `tests/design-assets.spec.ts`다. 인증 화면을 검사하는 기존 테스트 절차는 #14에 맞추되 새 동동체 검증은 유지한다. 로그인 화면 소스와 수면 동작 소스는 이번에 수정하지 않았다.

## 후속 화면 보완 — 2026-11-20

- 이메일 로그인/회원가입 공통 시트의 개발 안내 및 전문 상담 관련 하단 문구2개를 제거했다. 입력 제한 안내·오류·가입/로그인 동작은 유지한다.
- 로그인 석상은 팀 제공 `login-socrates.png`(364×651)로 교체했다. 다른 화면의 기존 석상은 유지한다. 원본에 흐림이 포함돼 추가 CSS blur는 제거하고 고유 비율을 유지한다.
- 메인 메뉴 설정/MY, 추천 카드 안의 종류·조작 안내, 수면 실행/종료에도 동동체를 적용한다. 카드 아래 남은 문장과 일반 본문은 기존 Pretendard다.
- 문구를 제거해도 API 연동 범위는 바뀌지 않는다. real 모드의 인증/프로필만 실제 백엔드를 호출하고 대화·기록은 `previewApi`의 MSW 응답과 탭 메모리를 사용한다. 실제 상담 및 기록 API 연결은 별도 남은 작업이다.
