### 구현에서 유지한 차이

- 추천 화면은 시각적 상단 제목을 숨기되 접근 가능한 h1을 유지한다. 원본에 없는 뒤로가기 링크는 기존 웹 복귀 경로로 유지했다.
- 추천 CTA 바로 아래 기록 상세 링크를 배치했다. PRD D20의 전체 항목·점수는 그 아래 계속 제공하며 이미지처럼 숨기거나 삭제하지 않았다.
- 기록 상세의 요약·점수·항목·대화 펼침을 하나의 흰 카드로 묶었다. 항목 수/내용에 따라 높이는 달라진다. 원본 요약 카드 내부의 모든 padding/radius를 추출한 것은 아니다.
- 메뉴/달력은 최소 터치 영역과 실데이터의 스크롤을 유지한다. 후순위 AI 분석·기록 숨김·탈퇴 등은 구현 완료로 가장하지 않는다.

## 글꼴과 자산

- 본문 Pretendard는 [공식 배포처](https://github.com/orioncactus/pretendard)의 Variable WOFF2를 로컬 제공한다. SIL OFL 원문을 함께 배포한다. 폰트 굵기400/600을 실제 파일에서 렌더링한다.
- 메뉴·MY 메뉴·추천 제목·동적 결과 요약의 **메모먼트 꾹꾹체**는 [공식 안내](https://www.memoment.kr/font)의 웹폰트 제한과 파일 재배포 금지를 확인했다. 파일을 프로젝트에 넣거나 임의 WOFF 변환을 하지 않는다. 웹 임베딩 허락 또는 정적 글자 자산 제공 여부를 팀과 확인할 대상이다. 메뉴18px, MY 메뉴16px, 추천 제목20px, 동적 요약15px은 Pretendard로 대체한다. 고정 텍스트는 내보낸 SVG로 교체 가능하지만 동적 AI 요약은 SVG로 대체할 수 없다.
- Figma 자체에서도 두 글꼴이 누락된 상태다. 따라서 캔버스의 대체 글꼴 모양을 원본 폰트 모양이라고 판단하지 않았다. 위 표는 속성에 지정된 글꼴명/수치를 읽은 것이다.
- 로고 이미지 미리보기의 다운로드는 브라우저 URL 보안 정책에서 data 프로토콜을 차단했다. 우회 추출하지 않았다. 로고·일반 양·수면 양·석상2종·아바타의 개별 PNG/SVG 내보내기 파일이 아직 필요하다. 전체 캡처를 잘라 정식 자산으로 사용하지 않는다.

## 미일치와 검증 한계

1. 정식 이미지·아이콘과 꾹꾹체가 없어 **전체 시각 일치 완료가 아니다**. 기존 Canvas 조작과 임시 아바타를 보존한다.
2. 원본 사용자 글자 `#FFF9F2` / 배경 `#909CB2`는 작은 본문 대비가 낮다. 앱은 기존 진한 글자 `#222C3D`를 유지하며, 원본과의 의도적인 차이로 기록한다. 팀 검토 없이 원본 색을 수정하지 않는다.
3. 위 표에 없는 수치, 잠긴 달력/탭 하위 컴포넌트의 세부 치수, 그라데이션 정지점·그림자·프로토타입 전환 시간은 아직 원본 속성 전수 확인 전이다. 첨부 화면 기반 구현과 섞어 원본 수치라고 표기하지 않는다.
4. Dev Mode는 현재 파일에서 업그레이드 안내가 나타나 Design 패널로 확인했다. MCP 연결 실패와 사이드패널 읽기 성공을 별개로 기록한다.
5. QA는 실제 프론트 흐름과 반응형·서체 로딩을 검사한다. 예시 AI/인증/메모리 저장을 실제 백엔드 검증으로 표현하지 않는다.
