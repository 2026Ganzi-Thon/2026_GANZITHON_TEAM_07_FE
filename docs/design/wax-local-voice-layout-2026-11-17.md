## 왁뿌볼

기존 hitShell은 남은 조각을 거리순 정렬해1~2개를 파괴했다. 이미 깨진 곳을 연타해도 다른 위치로 입력이 전달되는 원인이었다. 이제 전체 조각(깨진 조각 포함)의 다각형 중 터치 좌표를 포함하는 하나만 고른다. 그 조각이 이미 깨졌으면 파괴 없이 반환하고 다른 조각으로 넘어가지 않는다. 공유 경계는 고정 순서의 한 조각에 귀속한다. 본체의 실제 알파 경계 판정도 유지한다. 조각 분할 범위를 전체300×290 캔버스로 확장해 가장자리 원화가 분할 사각형 밖이라는 이유로 무반응/누락되지 않도록 했다.

깨진 조각 타임스탬프가 새로 바뀐 입력에만 파열음을 재생한다. 동일 구멍 연타에 파열음을 반복하지 않는다. 모든 껍질이 없어졌을 때는 기존 내부 눌림 소리를 유지한다. 키보드도 같은 중앙 좌표를 사용하며 다른 위치를 자동 선택하지 않는다.

일부 조각만 깨졌어도 손을 뗀 뒤 기존 대기/복원 곡선으로 원상복귀한다. 따라서 투명 영역에 걸친 조각까지 모두 깨야 다시 쓸 수 있는 문제가 없다. 누르고 있는 동안 복원은 멈추고, 복원 완료 후 같은 위치를 다시 깰 수 있다. 이는 이미지 전체의 실제 연속 균열 물리가 아닌 다각형 조각 단위 구현이다.

## 음성 화면

사이드패널에서 Figma `72:2777` AI(음성) 프레임을 다시 열어402×874와 하단 패널/캐릭터 구성을 확인했다. 원본을 편집하지 않았다. 기존 D37의 세부 측정표는 유지하며 이번 조정은 웹 반응형 보완이다.

D48에서 안내·전사·답변 카드를 세로로 쌓아 패널이 과도하게 커졌다. 패널을 최대324px/가용 높이38%(최소250px)로 제한하고 타이머/상태, 스크롤되는 내용 영역, 고정 조작 버튼의3행으로 나눴다. 높이600px 이하에서는 최소160px·마이크64px 보완을 적용한다. 정상 높이의 마이크115px/보조59px 및 radius67은 유지한다.

중간 전사와 최신 답변은 같은 내용 영역에 번갈아 표시한다. 최초 인사는 중복 카드로 넣지 않는다. 전체 대화는 채팅 보기에서 확인하며 입력은 유지한다. 이미지 높이는 화면의76%, 상단은16% 또는64px+safe-area 중 큰 값으로 정해 기존 고정658px를 빼던 배치 오류를 제거했다. 얼굴과 품 안의 말랑이를 패널 위로 노출한다. 제공 원본 이미지 자체는 바꾸지 않았다. 변경 수치는 Figma에서 새로 측정한 값이 아닌 웹 조정값이다.

## 음성 연결 경계

Chrome에서 인식 시작/경과시간은 표시되지만 말해도 전사 결과가 나타나지 않는다는 재현을 전달받았다. 사이드패널은 network 오류이며, 마이크 레벨 확인에서 입력 신호가 확인됐다. 입력 신호 존재만으로 브라우저 전사 서비스의 정상 동작을 보장하지 않는다. Chrome 무응답의 정확한 원인은 미확정이다.

기존10초 시작 타임아웃은 onstart에서 해제되므로 시작 후 결과 없는 상태를 잡지 못했다. 이제 시작 후 또는 마지막 전사 결과 후20초간 결과가 없으면 인식을 중단하고 미확정 글을 초안에 보존하며 입력 확인/재시도/텍스트 복귀를 제공한다. 음성 인식 공급자 연결을 고친 것으로 표시하지 않는다. 실제 Chrome 한국어 전사 성공은 여전히 미확인이다.

후속은 Chrome의 실제 오류 이벤트/서비스 응답 확인 또는 인증된 백엔드 STT 연결이다. 임의 자막·외부 API 키·운영체제 보안 설정 변경은 하지 않았다. [인식 오류 종류](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognitionErrorEvent/error), [로컬 처리 옵션과 지원 한계](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally).

검증 근거와 실패/재검사는 [QA](../qa.md)에 기록한다.

최종 빌드·단위110개 통과. 최초 브라우저20개 중19개 통과 후 키보드 검사 준비 조건을 수정했고 최종10개 재검사 모두 통과했다. 실제 음성 인식 서비스 연결은 미해결이다.
