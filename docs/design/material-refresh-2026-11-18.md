# 말랑이 자산·상호작용·사운드 변경

## 최종 동작

- 웹 후속 준비: 하트 상단 얇은 2셀을 인접 영역에 포함해 7셀로 분할하고 파편 애니메이션이 끝까지 사라지도록 한다. 구름은 기존 내부 색을 유지하며 외부 껍질만 12% 하늘색 틴트로 구분한다. 버터 분할·음원·전체 파괴 후 조작/대기 복원 정책은 유지한다. 상세 상태는 [웹 반영 준비](../emotion-wax-web-release.md)를 따른다.

- 버터 이미지를 새 제공 원화로 교체하고 표시 영역과 투명 영역 입력 판정을 맞췄다.
- 버터·하트·구름은 접촉한 조각만 파괴한다. 전체 파괴 후 안쪽을 조작하며 대기하면 껍질이 복원된다. 누른 채 유지하는 것만으로 파열음을 반복하지 않는다.
- 슬랑이는 제공 MP3 원본을 누를 때1회 재생한다. 드래그에는 원본 질감 구간을 겹친 지속 음원을 별도로 사용하며, 이동 속도·당김 정도에 따라 음량/필터/재생 속도를 완만하게 조절한다. 원본 타격음을 드래그마다 반복하지 않는다.
- 지속음은 이동이 멈추면 감쇠하고, 손 떼기·취소·음소거·음량0·이탈 시 정리한다. 비활동 시 타이머와 오디오 노드를 정리한다.
- 스퀴시는 제공 녹음의 누름/복원 구간을 분리한다. 복원3번은 높은 끝음이 집중된 구간을 제외했다.
- 기본 효과음은 켜짐/35%이며 사용자 조작 후 활성화한다. 로딩 중 다른 합성음을 섞거나 이전 입력을 지연 재생하지 않는다. 로드 실패 시 기존 대체음을 사용한다.

## 동일한 음원으로 실행하기

슬랑이 원본 MP3 1개, 스퀴시 누름3개/복원3개, 최종 확인한 왁뿌볼 WAV3개를 `public/assets/audio`에 포함한다. 왁뿌볼은 기존 로컬 추출본과 파일 바이트가 같고 재생 속도·필터·음량·끝단 처리를 유지한다.

`npm ci` 후 `npm run dev`, 또는 `npm run build` 후 `npm run preview`로 실행한다. `.env.local`, 별도 디스크, 원본 영상, FFmpeg/Python은 앱 실행과 빌드에 필요하지 않다. `/__local-wax__` 미들웨어와 `VITE_LOCAL_WAX_REFERENCE` 분기를 제거했다. 기존 로컬 설정이 남아 있어도 읽지 않는다.

원본에서 자산을 다시 만들 때만 다음 스크립트를 사용한다(NumPy, soundfile, FFmpeg 필요). 일반 개발자는 실행할 필요가 없다.

- `python scripts/prepare_supplied_audio.py <MP3폴더> <FFmpeg경로>`: 슬랑이·스퀴시만 생성하며 최종 왁뿌볼 파일과 manifest 항목을 보존한다.
- `python scripts/extract_wax_reference.py <영상경로> <FFmpeg경로>`: 최종 영상의1.44–2.10/2.48–3.18/3.52–4.14초를 추출해 왁뿌볼 파일과 manifest만 갱신한다. 다른 재질은 보존한다.

원본 녹화·개인 경로·환경 파일·QA 산출물은 저장소에 포함하지 않는다.

## 코드·출처

- `audio.ts`: 입력별 재생·음소거·로드 처리
- `slimeDragSound.ts`: 지속 질감 생성·이동 반응·노드 정리
- `useToyInteraction.ts`: 입력과 물리/오디오 연결
- `scripts/prepare_supplied_audio.py`: 제공MP3의 원본 복사/표본 가공
- `public/assets/audio/supplied-material-manifest.json`: 파일별 원본·가공·해시
- 왁뿌볼 추출물도 같은 manifest에 원본 파일명·구간·해시를 기록한다.

## 검증

전체 단위124개, TypeScript/Vite 빌드, Chromium/WebKit 35개 시나리오를 통과했다. Web Audio가 없는 WebKit의 슬랑이 지속음 1개는 제외했다. 오디오 재생 계측은 Chromium이며 WebKit의 다른 오디오 검사는 미지원 안내 경로다.

개인 환경 파일과 원본 영상이 없는 별도 복사본에서 npm ci/빌드 후 HTML·JS·CSS·음원10개가 기존 빌드와 동일함을 확인했다. 자산 재생성 스크립트도 동일한 파일을 만든다. 상세 실패 원인·재검 및 환경 제한은 [QA 기록](../qa.md)을 따른다.

현재 로컬 소리는 수용된 상태이며 자동 재생 계측을 실제 청취 검증으로 대체하지 않는다. 실제 모바일 기기 성능·한국어 음성인식·API 연동은 이번 변경 범위가 아니다.
