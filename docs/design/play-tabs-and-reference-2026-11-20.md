# 말랑이 선택·로그인·음성 화면 후속 변경 — 2026-11-20

- 메인의 첫 누름/드래그/키보드 입력은 체험 전환만 한다. 해당 포인터가 끝나고 전환 시간이 지난 뒤 별도 입력부터 물성과 소리가 반응한다.
- 체험 상단은 슬랑이→스퀴시→왁뿌볼 탭, 하단은 해당 종류의 3개 모양이다. 종류별 마지막 선택을 현재 앱에서 유지한다. 본체·썸네일·선택 강조가 일치한다.
- 상단 탭·소리·메뉴는 한 줄이 기본이다. 앱 내부 폭이 365px 이하로 공간이 부족할 때만 소리를 메뉴 아래에 둔다. 기기 이름으로 분기하지 않는다.
- Home과 /malangi가 ToyStage/ToyToolbar/ToyVariants/ToyFinish를 공유한다. 추천·기록에서 들어온 체험은 출발 화면으로 돌아간다. 늦게 끝난 종류 선택 요청은 화면 이탈 뒤 경로를 변경하지 않는다.
- 스트레스 기록은 표시용 화남 PNG를 사용한다. 저장된 감정명/서버 enum은 바꾸지 않는다.
- 로그인은 흰 배경·좌상단 로고·하단까지 이어지는 큰 석상과 그 위 이메일 버튼으로 배치한다. 제공 원본을 contain하며 원본 자체의 오른쪽 경계는 임의 생성/수정하지 않는다. 가입 순서는 이메일→비밀번호→닉네임이다.
- 음성 화면은 은은한 따뜻한 배경과 회색 반투명 하단 패널, 약한 blur·흰 글씨로 수정한다. 밝은 유리 테두리 반사를 줄인다. 물리적 굴절은 아니다. 듣기/오류 상태의 조작 접근성을 유지한다.
- 최신 Figma 수치 조회는 재인증 오류로 미완료다. 이번 배치는 제공된 로그인/AI(음성)/말랑이 참고 이미지 기준이며 정확한 Figma 수치 일치를 주장하지 않는다.
- Cafe24 동동체 범위는 이전 자산 명세를 유지한다. 추천의 남은 문장은 Pretendard다. 수면 기능과 인증 로직은 변경하지 않았다.
