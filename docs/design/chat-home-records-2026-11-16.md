## 원본과 웹 적용의 구분

- 사이드패널에서 Figma `113:658` ‘마음 보관함 기록 선택’ 프레임 402×874/#FFF9F2 및 카드 구성·동작 위치를 다시 확인했다. [원본 링크](https://www.figma.com/design/vmbKI4ltraNNxZSlhmg27N/?node-id=113-658).
- 기존 측정된 Pretendard/제목 15px와 본문 계층은 유지했다. 카드 내부 배치·동작 위치는 원본에 맞췄으나 모든 하위 레이어 숫자를 새로 추출한 것은 아니다. 동적 내용 높이와 44px 터치 영역은 웹 대응이다.
- 말풍선의 새 둥근 꼬리/그라데이션/그림자/모션은 사용자 요청으로 보완한 웹 디자인이다. 원본 고정 수치를 그대로 복제했다고 주장하지 않는다. 기본 글씨는 Pretendard12/18, 작은 가로 화면11/18이다.
- 양 PNG는 y45,h200으로 300×290 Canvas에 그린다. PNG 자체의 상단 투명 여백을 포함해 실제 상단 약23%를 기준으로 배치한다. CSS의 박스만 비교하지 않고 렌더링된 불투명 픽셀 상단과 말풍선 꼬리 사이를 검사한다.
- 말풍선 등장0.55초, 4.8초 주기의 3px 떠오름. 캐릭터 호흡과 같은 주기이나 약간 지연한다. 줄인 모션·조작 상태에서는 부유를 멈춘다.
- Figma의 예시 ‘사용 말랑이’는 실제 사용 API가 없으므로 ‘당시 추천 말랑이’로 표시한다. 수집하지 않은 새로운 관점이나 점수를 채워 넣지 않는다.

## 음성의 남은 제약

직접 UI에서 실제 브라우저 인식기를 시작했지만 `network` 오류로 종료됐다. 이는 브라우저 음성 인식 서비스 통신 실패이며 사용자 인터넷/마이크 장치가 원인이라고 단정할 수 없다. 현재 프론트 오류 복구는 보완했지만 실제 한국어 전사 성공은 확인하지 못했다. 가상 이벤트 테스트는 중간 전사·최종 1회 전송·권한 거절·연결 실패·시작 시간 초과·화면 이탈 처리만 검증한다.

운영 STT 공급자와 서버 중계/스트리밍 계약은 미정이다. API 키나 대체 서비스 없이 모든 브라우저에서 작동한다고 보장하지 않는다.

## 검증

실행 결과와 발견/수정 내역은 [QA 기록](../qa.md)의 D39 구간에 기록한다. 이전 D38 검사 횟수를 이번 변경의 통과 횟수로 재사용하지 않는다.


직접 검수에서 음성 화면의 ‘글로 계속하기’ 이후 오류 안내가 남는 문제를 발견해 복귀 시 해제하도록 수정했다. 자음만 들어온 시트 첫 입력도 입력창에 남겨 다시 고칠 수 있다. 기록 카드의 삭제 버튼은 WebKit에서도 확인창 종료 후 초점을 돌려받도록 열기 전에 명시적으로 초점을 지정한다.
