# D50 — 왁뿌볼 안쪽 조작과 합성 파열음

2026-11-17 · 로컬 검토. D49의 **부분 파괴 자동 복원**을 대체한다. 음성 화면/진단, 로그인, 수면은 변경하지 않는다.

> 이 문서는 D50 이력이다. 부분 파괴 중 조작과 효과음 설계는 [D51 현재 사양](wax-complete-crunch-2026-11-17.md)으로 대체했다.

## D50 당시 동작

- 실제 누른 다각형 조각 하나만 깨진다. 같은 구멍을 반복 입력해도 남은 이웃 조각을 대신 깨뜨리지 않는다.
- 껍질이 일부 남아 있어도 깨진 접점의 안쪽은 국소적으로 눌리고 늘어난다. 남은 원화 껍질은 별도 레이어로 유지한다.
- 부분 파괴 상태는 그대로 유지한다. 보이는 껍질을 모두 벗긴 뒤에는 전체 안쪽을 자유롭게 만진다. 마지막으로 손을 뗀 뒤 약1.78초 대기하고650ms 동안 껍질이 돌아온다. 다시 잡으면 복원이 멈추고, 놓은 뒤 재개한다.
- PNG 알파 영역과3논리px 격자를 대조해 완전히 투명한 조각은 제외하고, 격자12점(약108논리px²) 미만인 작은 끝 조각은 독립 조각으로 남기지 않도록 인접 영역을 다시 분할한다. 전체 PNG를 덮는 분할을 다시 만들기 때문에 작은 부분이 다른 곳을 눌렀다는 이유로 통째로 사라지지 않는다. 모양 변경/초기화에도 같은 판정을 적용한다. 가장자리 입력을255px에서 잘라버리던 좌표 제한을290px 전체 높이로 고쳤다.
- PNG를 사용한2.5D 변형이며 실제 체적 시뮬레이션이 아니다. 안쪽은 제공 원화가 아닌 절차적 색상층이다.

## 효과음과 출처

- `waxSound.ts`에서 직접 생성한 PCM을 사용한다. 짧은 저음 파열 몸통·불규칙한 미세 균열·짧은 감쇠를 합성한다. 매 입력의 노이즈/간격/음높이가 달라지고 포인터 압력은 제한된 세기/길이에 반영된다. 압력 미지원 마우스는 중간 세기를 사용한다.
- 새 껍질 파괴: 합성 파열음. 기존 구멍의 누름/드래그: 기존 부드러운 스퀴시 표본. 정상 손 떼기: 지연된 복원 표본. 같은 구멍에서 파열음을 반복하지 않는다.
- 참조 사이트의 오디오 파일·Base64 데이터·합성 소스는 복사하지 않았다. 사이트 음원 재사용 허가는 확인되지 않았다. 정확히 같은 소리를 재현했다는 의미가 아니다.
- 기존 shell-1~3 파일과 출처 이력은 보존하지만 실행 중 로딩/재생하지 않는다. 현재 로드 대상은 slime3+foam3+foam-release3+bubble3=12개다.
- 기본 ON/첫 사용자 조작 시 활성화, 최대4개 동시 음원, 음량0·음소거·숨김·이탈·새 입력 시 예약 복원 취소는 유지한다.

## 검증

최종 빌드·단위114/114·Chromium/WebKit 브라우저10/10 통과. 시행착오와 검증 범위는 [QA 기록](../qa.md)의 D50을 따른다. 브라우저 합성/호출 계측과 실제 기기 스피커 청취 평가는 구분한다. 생성 파형의 유한 값·클리핑 한도·앞뒤 감쇠·입력 간 차이, 재생 취소, 세 모양의 같은 자리 반복/전체 파괴/복원과 키보드를 검사한다.

로컬 미리듣기 `artifacts/d50-wax-fracture.wav`는 같은 합성 함수로 만든 강도3단계 예시이며 실시간 마스터 음량/필터를 거친 스피커 녹음이 아니다. 산출물은 Git 제외다.
