# D48 — 재질 효과음·양 표정·음성 입력

2026-11-17. 구현 검토 기록.  로그인·수면·서체는 이번 변경 대상에서 제외한다. D47의 복원음 선택과 이전 D37의 답변 읽기 정책을 이 문서로 대체한다.

## 음성 입력 동작

음성은 사용자 입력 수단이다. 테스의 답변은 텍스트로만 표시하며 TTS와 답변 읽기 설정을 제거했다.

1. 채팅 입력칸의 마이크를 눌러 시작한다. 실제 인식 시작 이벤트 뒤에만 듣는 상태와 경과시간을 표시한다.
2. 말하는 중간 결과는 음성 화면의 전사 영역과 동일한 채팅의 임시 말풍선 하나에 갱신한다. 아직 보관된 메시지는 아니다.
3. 브라우저 인식기가 최종 문장으로 확정하면 한 번 자동 전송한다. 고정된 침묵 시간으로 확정한다고 보장하지 않는다.
4. 응답 대기 중에는 인식을 멈춘다. 답변은 음성 화면의 ‘테스의 답변’과 채팅에 표시하고, 다음 자유 입력 단계에서 다시 듣는다.
5. 감정·강도 선택 단계에서는 채팅 카드로 이동한다. 선택을 마치면 다시 음성 입력이 이어진다.
6. ‘채팅 보기’는 입력을 계속 유지하며 전체 대화를 보여준다. ‘음소거’는 듣기를 멈추고 ‘중단’은 텍스트 입력으로 돌아간다. 중간 인식 내용과 기존 작성 중 글은 초안에 보존한다.
7. 입력 검사를 통과하지 못한 최종 문장은 초안에 남기고 다시 듣는다. 늦게 도착한 이전 인식 콜백은 무시한다.

`useVoice`는 인식 수명주기만 관리한다. `VoiceView`가 입력 안내·중간 전사·최신 답변을 표시한다. 패널은 기존 원형 버튼·글래스 배경을 유지하되 내용에 따라 높이가 늘고 낮은 화면에서는 내부 스크롤을 허용한다. 신규 안내와 답변 카드는 음성 입력 요구에 맞춘 구현이며 Figma 원본 측정값으로 주장하지 않는다.

## 실제 연결 상태와 진단

실제 사이드패널에서 가상 인식 이벤트 없이 시작했지만 `network` 오류가 재현됐다. 별도 `getUserMedia` 입력 크기 확인에서는 입력 신호가 확인됐다. 따라서 이 환경에서 마이크 신호와 브라우저 음성 인식 서비스 연결을 구분할 수 있지만, 오류의 네트워크/브라우저 제공자 내부 원인은 확정하지 않았다. Chrome에서 실제 한국어 전사 성공은 아직 확인하지 못했다.

오류 화면의 ‘마이크 확인하기’는 최대6초간 입력 크기만 측정한다. 녹음 파일 생성·재생·저장·업로드를 하지 않는다. 권한 응답 대기는15초로 제한하고 중단·화면 이탈·탭 숨김 시 트랙과 AudioContext를 닫는다. 늦게 허용된 스트림도 닫는다. 이 진단 성공은 전사 성공이 아니다.

브라우저 SpeechRecognition은 제공자 인식 서비스를 사용할 수 있다. 운영 환경에서 일관된 지원이 필요하면 인증된 백엔드 STT 연결과 중간/최종 전사 이벤트 계약이 후속 작업이다. 현재 서버 STT·API 키·외부 유료 서비스는 추가하지 않았다. [브라우저 인식 문서](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), [마이크 권한 문서](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).

## 재질 효과음

기존 기본 ON·음량35%·첫 조작 활성화·동시4개 제한과 취소 정책을 유지한다. 동일 표본의 연속 선택을 피하고 누름 재생 속도를 소폭 달리한다. 드래그 강도는 이동 속도에 따라 달라진다.

| 재질 | 적용 | 원음의 실제 정체 |
|---|---|---|
| 스퀴시 | 누름과 복원을 별도 표본으로 분리. 복원은 재질별50/90/180ms 대기 후 재생 | 기존 젖은 스펀지 녹음. 복원은 이를 역방향·필터·포락선 처리한 효과음이며 실제 마른 폼 복원 녹음이 아님 |
| 슬랑이 | 기존 점성 표본 + 강한 드래그에서 간헐적인 작은 팝 | 플라스틱 면에 붙인 흡착컵 소리 가공 |
| 왁뿌볼 | 기존 나무 균열 대신 짧은 껍질 파열 계열 표본3개 | 플라스틱 병을 찌그러뜨린 녹음 가공이며 실제 왁스 녹음이 아님 |

원음은 BigSoundBank의 CC0 자료다. [병 0775](https://bigsoundbank.com/plastic-bottle-crushed-1-s0775.html), [흡착컵1261](https://bigsoundbank.com/suction-cup-on-plastic-s1261.html), [스펀지0778](https://bigsoundbank.com/sponge-and-foam-s0778.html). 레퍼런스 서비스의 파일을 복사하지 않았다.

`scripts/prepare_material_audio.py`는 제공된 원음 디렉터리에서9개 mono32kHz PCM16 파일을 만든다. 원음/출력 SHA-256·구간·가공 규칙·피크/RMS는 `public/assets/audio/material-manifest.json`, 출처/조건은 같은 폴더의 `LICENSES.md`에 있다. 오디오 준비용 Python 도구는 앱 런타임 의존성이 아니다. 기존 사용하지 않는 crack 파일은 삭제하지 않았다.

## 양의 미세한 표정 반응

새 눈이나 입을 덧그리지 않는다. 기존 PNG 메시에서 얼굴 중심을 누를 때 눈·입·볼 주변이 아주 조금 모이고 올라오도록 했다. 얼굴 반경 밖은0, 다른 모양은0, 깊이0이면 변형0이다. 손을 떼면 기존 복원 곡선에 따라 원본으로 돌아온다. WebGL과 Canvas 대체 출력에 공통 적용하며 원본 PNG는 변경하지 않았다.
