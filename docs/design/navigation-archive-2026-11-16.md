새 하단 진입부와 우상단 4개 메뉴의 완성 프레임은 제공되지 않았다. 다음 값은 **웹 구현값**이며 Figma에서 직접 측정한 값이라고 보지 않는다.

- 신규 ‘설정/MY’는 제공 이미지의 일반 서체에 맞춰 Pretendard16/600으로 적용하며 신규 항목의 원본 글자 속성은 미확인이다. 기존 3개 항목만 확인된 꾹꾹체18px이다.
- 상단 메뉴48px(짧은 가로 화면44px), 팝업 폭200px, 행 최소44px/간격8px. 팝업은 버튼 아래에 열린다. 수면 아이콘은 채워진 초승달, 나머지는20px 선형 아이콘이다. 원본 SVG는 미수령이므로 Lucide 기반 근사다.
- 하단 진입부 최소76px, 손잡이34×4px, 문구 Pretendard14/500. 별도 감성 문구나 미리보기 문구를 추가하지 않는다.
- 보관함 본문 좌우24px(좁은 화면20px), 탭 최소38px + 상하 패딩4px, 달력 날짜 최소48px, 카드 모서리16px. 주간 감정 원36px(좁은 화면32px), 목록 감정 원40px. 상세 원본 수치 미확인 영역은 첨부 레이아웃과 터치/반응형 기준으로 구성했다.
- 위 수치 전체를 화면 폭 비율로 일괄 확대/축소하지 않는다. 글꼴/주요 크기는 유지하고 폭·줄바꿈·스크롤이 반응형이다. 입력창16px은 모바일 자동 확대 방지 목적이다.
- 주간과 목록은 Pretendard다. 감정 이모지는 운영체제에 따라 다르게 보일 수 있으며 정식 감정 이미지 수령 시 교체한다.

## 메인 동작

1. 중앙 말랑이·우상단 메뉴·하단 ‘테스와 이야기하기’를 표시한다.
2. 하단 탭 또는 위로40px 이상(수평 이동보다 큰 거리) 쓸어올리기로 기존 대화 시트를 연다. 수평/하향 드래그는 진입하지 않는다. 키보드 Enter/Space도 지원한다.
3. 시트의 선택적 첫 이야기는 로그인 경유 후 한 번 전달된다. 닫으면 메인 초안과 호출 버튼의 초점을 유지한다. 대화 시작 시 기존 전체 대화 경로로 이동한다.
4. 우상단 팝업은 수면 모드·감정 기록·마음 보관함·설정/MY 순서다. 감정 기록은 같은 시트를 연다. 외부 클릭·Escape로 닫는다. 수면은 아직 준비 안내다.
5. 말랑이를 누르면 같은 Canvas에서 조작하며 하단 진입부만 은은하게 숨긴다. 메뉴는 유지되고 조작 종료 시 하단 진입부가 복귀한다. 캐릭터 박스가 이동하지 않는다.

독립 말랑이 체험 경로의 메뉴 위치는 기존 하단으로 유지한다. 신규 독립 화면은 추가하지 않았다.

## 대화 말투

- AI 발화만 절제된 하오체다. 예: ‘오늘 어떤 일이 있었소?’, ‘그때 가장 먼저 떠올랐던 생각은 무엇이었소?’
- 질문 단계/완료 규칙, 사용자 문장, 카드/버튼, 오류·위기 안내는 기존 의미를 유지한다. 전체 문자열을 일괄 치환하는 런타임 처리는 하지 않는다.
- 현재 변경은 프론트 예시 대본과 reducer 안내 발화다. 실제 모델 프롬프트 또는 서버 출력은 미연동이며 이 수정으로 운영 AI 말투가 변경된 것은 아니다.

## 보관함 데이터와 행동

- 월간: 일~토 달력, 선택일 배경, 대표 감정별 점, 날짜별 기록. 범례 기본4종과 해당 월에 실제 등장한 나머지 감정을 표시한다. 최종 선택 가능 감정 enum을 바꾼 것이 아니다.
- 주간: 월~일 실제7일. 월/연도 경계도 포함하며 이동·오늘 복귀를 지원한다. 각 날짜의 가장 최근 기록 감정과 복수 기록 개수를 표시한다. 빈 날짜는 점선 원으로 남긴다.
- 주간 횟수는 해당 주 전체 기록 수다. 평균은 같은 기록에서 전후 점수가 모두 있는 경우만 합산한다. 0점은 유효하며 누락 점수는 제외한다. 쌍이 없으면 ‘— → —’, 있으면 소수점 한 자리다. 평균 옆 설명에는 계산에 사용한 기록 수를 담는다. 이는 프론트 산술 집계이며 AI 누적 분석이 아니다.
- 목록: 선택한 월의 기록을 최신순으로 표시한다. 감정/날짜/시간, 한 줄 요약, 전후 점수·당시 추천 말랑이, 상세 진입을 제공한다. 요약 전체는 상세에서 확인하며 추천을 실제 사용 이력으로 표시하지 않는다.
- 주간·월간 날짜 선택 시 아래 목록이 해당 날짜 기록으로 바뀐다. 조회/오류/빈 상태·상세 삭제와 캐시 갱신은 기존 동작을 유지한다.
- 날짜 기준은 브라우저 로컬 시간대다. 실제 서버 연결 시 시간대와 기간별 조회·페이지네이션을 맞춰야 한다.

## 범위와 QA

수면·음성·실제 인증·AI·영속 저장은 추가하지 않았다. 폰트/이미지 출처는 [자산 문서](../assets.md), 현재 자동 검사와 한계는 [QA](../qa.md), 연결 지점은 [인수인계](../handoff.md)를 따른다. 전체 Figma 픽셀 일치·원본 SVG 일치·실제 휴대폰 검증 완료를 주장하지 않는다.
