로딩 후 메인화면에는 말랑이 하나가 놓여 있을 예정입니다! (이건 말랑이 부분 개발하시는 분이 넣어주시면 될 것 같습니다..!)

회의에서 나온 대로 우측 하단에 메뉴 버튼을 놓아서 그거 누르면 수면모드/감정정리/마음 보관함으로 이동할 수 있게 해뒀구요 (피그마에서 토글해 볼 수 있습니다!)

우측 상단 톱니바퀴 버튼 누르면 MY/설정칸으로 이동할 수 있게 해두었습니다! 안의 내용은 내일중으로 작업해드리겠습니다..ㅠㅠ 수정거리가 있어서요

메인 화면의 말랑이를 누르면 배경 색상이 바뀌면서 (피그마 와이어프레임 참조) 화면 상단에 (설정 버튼보다는 아래) 말랑이 종류를 변경할 수 있는 버튼이 들어갈 예정이구요 다른 복잡한 버튼 없이 화면 중앙에 말랑이만 크게 상호작용 할 수 있도록 할 예정입니다! (우측하단 메뉴 버튼 동일)

수면모드를 누르면 기획서의 내용대로 말랑이가 수면모드에 돌입하고 배경 색상도 어둡게 바뀝니다.
슬라이드되어 열 수 있는 설정 칸이 있고 그곳에 ASMR, 음원 등 사용자가 설정할 수 있도록 버튼 제작 할 예정입니다! 설정을 마친 후 설정칸 아래의 수면모드 실행 버튼을 누르면 수면모드 실행 화면으로 넘어가서 (더더욱 화면이 어두워짐) 수면모드가 실행되게 해주셨으면 좋겠습니다!

감정기록부분은 살짝 고민중인데 "감정기록 시작하기" or "감정 입력하기" 화면이 따로 필요할지 아니면 바로 대화로 넘어가는것이 좋을지 고민중입니다!

AI대화창에서는 좌측 상단에 메인메뉴로 돌아갈 수 있는 나가기 버튼이 있고
그 아래에 소크라테스의 프로필, AI의 상태(고민을 듣는 중/ 생각중 / 입력중 등..) 채팅들이 있을 예정입니다
채팅 입력 칸에서는 좌측에 음성 대화로 넘어갈 수 있는 버튼이 있고 가운데는 입력창 우측에는 전송버튼이 있습니다.

음성 대화로 넘어가면 아이폰 통화처럼 소크라테스의 사진이 띄워지고 글래스 효과 입힌 사각형의 상태창 위로 좌측부터 순서대로 중단 / 음소거 / 채팅 버튼이 있을 예정입니다.

중단버튼을 누르면 음성 채팅이 중단되고 다시 텍스트 채팅 창으로 넘어가며, 음소거 버튼을 누르면 사용자 음소거, 채팅 버튼을 누르면 음성 통화를 하면서 채팅을 볼 수 있도록 했으면 좋겠습니다! (사용자가 말하는 내용, 소크라테스가 말하는 내용을 실시간으로 채팅으로 기록할 수 있을까요?)

그 다음 말랑이 추천 화면에서는 추천하는 말랑이를 크게 띄워두고 아래에 짧은 조언과 함께 화면을 구성할 예정입니다! 말랑이를 누르면 그 말랑이를 만질 수 있는 말랑이 화면으로 넘어갑니다.

마지막으로 마음 보관함은 회의에서도 나왔듯이 일단 기본적으로 월별 달력 느낌으로 제작할 예정이고, 시간이 나면 주간별이나 그 외의 방안도 추가할 예정입니다.

마음 보관함의 메인 화면에서 상담 하나하나의 기록을 눌러서 세부 기록을 볼 수 있고 화면 상단에는 테스형의 분석 레포트 결과 요약 (누르면 분석 레포트 상세 정보 확인 가능) 중앙에는 상담기록이 있는 캘린더를 둘 예정입니다.
