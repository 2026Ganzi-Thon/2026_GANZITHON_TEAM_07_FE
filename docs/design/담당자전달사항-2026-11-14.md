# 기획·디자인 전달 사항 요약

기준일: 2026-11-14. 전달받은 설명에서 제품 동작만 정리한 참고 자료다. 개인 메시지·인사·일정은 포함하지 않는다. 최신 적용 기준은 [D33 화면 기준](figma-update-2026-11-15.md) 및 PRD의 D34를 우선한다.

참조: [Figma](https://www.figma.com/design/vmbKI4ltraNNxZSlhmg27N/?node-id=71-244), [화면 참고](figma-overview-2026-11-14.png).

| 영역 | 전달된 방향 | 확정·구현 시 구분 |
|---|---|---|
| 메인 | 중앙 말랑이, 우하단 메뉴, 우상단 MY/설정 | 메뉴는 수면·감정 기록·마음 보관함. 최신 구현은 감정 기록에서 대화 시트 진입 |
| 말랑이 | 누르면 배경 변경, 상단 종류 선택, 중앙 상호작용 | 종류별 정식 자산 대기. 세 종류 전체 개방은 D34 적용 |
| 수면 | 어두운 배경, 슬라이드 설정, ASMR·음원 선택 후 실행 | 후순위·미구현. 밝기/타이머 등은 최신 시안 확인 필요 |
| 텍스트 대화 | 나가기·프로필·상태·메시지·입력창·전송 | 감정 기록 진입 방식과 강도 입력 UI는 후속 PRD/디자인 기준 적용 |
| 음성 | 석상·유리 패널, 중단·음소거·채팅 전환, 실시간 대화 기록 제안 | 실제 음성 연결·전사는 미구현. 공급자/API 계약 필요 |
| 추천 | 큰 말랑이, 짧은 조언, 체험 화면 연결 | 실제 추천은 서버 계약 필요 |
| 보관함 | 월별 달력·기록 상세, 주간 등 추가 보기 제안 | 현재 월간/주간/목록 UI 제공. 누적 AI 분석은 후순위 |
| 계정 | MY/설정 세부 화면 보완 | 운영 인증·가입·계정 관리 계약은 별도 |

디자인 시안의 완성 여부는 기능 연동 완료를 의미하지 않는다. 정식 자산 수령·적용 상태는 [자산 인계표](asset-handoff.md)를 따른다.
