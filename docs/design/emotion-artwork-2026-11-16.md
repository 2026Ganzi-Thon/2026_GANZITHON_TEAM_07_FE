# 보관함 감정 이미지 적용 — D43

2026-11-16. 팀이 전달한 PNG 12개를 주간 캘린더와 날짜별 기록 목록·목록 탭에 적용했다. 로컬 검토 단계이며 이번 변경은 커밋·푸시·PR 반영 전이다. Figma 원본을 수정하거나 이번에 새로 측정한 것은 아니다.

## 표시 규칙

대표 감정 `record.context.primary`로 그림을 선택한다. AI가 문장으로부터 추가 감정을 추측하거나 저장된 감정 이름을 바꾸지 않는다. 이미지 연결 범위와 대화/API의 선택 가능한 감정 목록은 별개다.

| 저장된 감정 | 파일 (`public/assets/design/emotions/`) |
|---|---|
| 모르겠음 | unknown.png |
| 불안 / 불안함 | anxious.png |
| 서운함 | disappointed.png |
| 속상함 | upset.png |
| 슬픔 | sad.png |
| 신남 | excited.png |
| 우울 / 우울함 | depressed.png |
| 평온 | calm.png |
| 행복함 | happy.png |
| 분노 / 화남 | angry.png |
| 감사함 | grateful.png |
| 기쁨 | joyful.png |

- 문자열 앞뒤 공백만 제거해 표시용 연결을 찾는다. 원래 저장값과 화면의 감정명은 유지한다.
- 스트레스·미등록 감정·감정 미선택은 중립 말풍선 아이콘을 사용한다. 이들을 명시적 ‘모르겠음’으로 바꾸지 않는다. 이미지 로딩 실패도 동일한 중립 표시로 처리한다.
- 주간은 가리지 않은 최신 기록의 대표 감정을 표시한다. 최신 기록에 감정이 없으면 이전 기록의 감정을 대신 가져오지 않는다.
- 하루 두 건 이상이면 건수 배지를 표시한다. 배지 공간은 최대 `99+`, 날짜 버튼의 접근 가능한 이름은 실제 전체 건수를 유지한다.
- 기록이 없는 날은 빈 점선 원을 유지한다. 가린 기록은 아이콘 선택·건수·주간 요약에서 제외하고 복원하면 다시 포함한다.
- 날짜별 목록과 목록 탭은 각 기록의 대표 감정에 같은 이미지를 사용한다. 월간의 색상 점·범례, 결과/상세의 색상 막대, MY 관리 카드 구조는 유지한다.

## 크기·간격·접근성

- 원본 12개는 모두 507×507 RGBA PNG이며 총 1,284,114바이트다. 변환·재압축·크롭 없이 바이트 그대로 복사했다. 출처·SHA-256은 `public/assets/design/manifest.json`에 있다.
- 주간 표시 영역은 기본 36×36px, 370px 이하 화면에서는 32×32px이다. 목록 영역은 40×40px이다.
- 투명 여백을 고려해 내부 이미지는 표시 영역의 135%로 중앙 정렬한다. 실제 얼굴·장식은 영역 안에 들어오며 원본 파일은 변경하지 않는다.
- 주간 이미지 위 8px 공간을 추가한다. 배지는 이미지 위쪽에 분리 배치해 그림 장식과 겹치지 않게 한다. 선택 윤곽선과 날짜 강조는 유지한다.
- 이미지는 장식 요소로 처리한다. 주간 날짜 버튼의 이름에 날짜·실제 건수·대표 감정을 제공하고 목록은 기존 텍스트를 유지한다. 이미지 실패가 날짜 선택이나 기록 상세 진입을 막지 않는다.

## 코드와 연동

- `emotionAssets.ts`: 감정 문자열과 PNG 경로의 연결. 서버 DTO가 확정되면 이 경계를 매핑한다.
- `EmotionIcon.tsx`/CSS: 주간·목록 공통 이미지 및 실패 대체 표시.
- `Archive.tsx`/CSS: 날짜별 최근 기록·배지·목록 배치.
- 현재 대화의 예시 감정 6개는 그대로다. 긍정 감정 등 나머지 자산도 해당 대표 감정이 기록에 들어오면 표시할 준비가 되어 있다. 사용자가 선택 가능한 목록을 12개로 확정한 것은 아니다.

검증은 [QA 기록](../qa.md)의 D43을 따른다. 검증용 날짜·다양한 감정 기록은 테스트 내부에서만 구성하며 제품에 예시 기록을 자동 삽입하지 않는다.
