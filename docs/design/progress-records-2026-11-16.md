## 실제 흐름

1. 대화 종료 버튼/화면 안 뒤로가기 → 확인창. 전송한 메시지가 없으면 보관 버튼 없음.
2. ‘여기까지 보관하고 나가기’ → 현재 스냅샷 저장 → 보관함. 감정·점수가 없어도 가능하나 추천을 생성하지 않는다. 작성 중 글과 미확정 음성 제외.
3. 저장 실패 → 확인창과 내용 유지 → 같은 id 재시도. 응답 유실 후 대화를 더 이어가면 동일 기록을 최신 스냅샷/최종 결과로 갱신한다. 오래된 재시도로 최신 기록을 덮어쓰지 않는다.
4. 기존 점수/결과 마무리 경로는 유지한다. 기본 mock 질문은 상황→감정/강도→생각→작은 실천까지만 묻는다. 생략한 관점·욕구·대처를 AI가 분석했다고 꾸미지 않는다.
5. 기록 상세의 ‘기록 가리기’ → 내용 접기. 일반 보관함의 월간/주간/목록/집계에서 제외. MY 기록 관리에서 ‘가린 기록’ 확인, ‘다시 표시하기’로 복원. 삭제와 다른 동작이며 암호 잠금은 아니다. 성공 시 진행 중 목록 요청을 취소하고 상세와 목록 캐시를 함께 갱신해, 즉시 뒤로 이동하거나 목록 재조회가 실패해도 이전 내용이 다시 노출되지 않도록 한다.
6. 추천 결과의 후보 선택 → 강조/양/안내/CTA만 변경 → CTA 클릭 시 선택한 종류 체험. 선택하지 않으면 추천 종류 사용. 기존 추천 필드 불변.

## 조언 규칙

사용자가 정한 ACTION이 있으면 그대로 표시하고 산책/몸풀기, 기록/메모, 휴식에 맞는 원본 아이콘을 표시한다. ACTION이 없으면 현재 감정에 따른 3개 범주별 3문구 중 기록 ID로 고정된 한 문구를 제공한다. 재렌더/후보 변경으로 문구가 흔들리지 않는다. 별도 선택은 사용자 행동으로 저장하지 않으며 ‘작은 조언’으로 표시한다. 이 규칙은 실제 AI 개인화가 아니다.

## API 연결 시 확인할 사항

`partial`, nullable `recommended`, `hidden`, `PATCH /__preview__/records/:id`는 프론트 예시 계약이다. 실제 abort/complete 상태, 미완료 대화 저장, 권한·보존 기간, 숨긴 기록 필터/집계, 되돌리기 범위는 서버 어댑터에서 맞춘다. 현재 로그인·대화·기록은 탭 메모리여서 새로고침하면 초기화된다. 브라우저 음성 인식의 실제 한국어 품질·실기기 마이크는 별도 검수가 필요하다.

## 검증

최종 실행 결과는 [QA 기록](../qa.md)의 D38 항목을 따른다. 검사는 정상 흐름뿐 아니라 저장/가리기 실패·재시도·계정 격리·0과null·긴 요약·후보 선택 후 이동·메인 비겹침·음성 상단 여백을 포함한다. 시험용 기록과 소스 원본을 구분하며 원격 업로드는 수행하지 않는다.
