# 전체 흐름 구현 현황

기준일: 2026-11-16. 전체 기능 연결을 우선한 1차 구현이다. [PRD](../prd.md)의 필수 화면을 예시 데이터로 연결한 구현 기록이며, 운영 서비스의 완료 선언이 아니다.

필수 기능 전체의 실제·임시·미구현 상태와 노션 17개 대분류/PRD AC01~31 대응은 [requirements-status.md](requirements-status.md)를 따른다. 이 문서의 화면 표만으로 기능 완료를 판단하지 않는다.

## 시안 전용 가정 — 제품 확정과 분리

- 로그인은 실제 이메일/소셜 인증이 아니다. 두 개의 고정된 체험 프로필을 명시적으로 선택한다. 인증 방식과 가입 UX는 여전히 미정이다.
- 계정별 예시 데이터를 분리하기 위해 대화·체험·보관함·상세·결과 진입 시 체험 계정 선택을 요구한다. 메인·설정·도움은 공개한다. 이는 실제 로그인 요구 시점 확정이 아니다.
- MSW가 `/__preview__/` 요청을 처리하며 모든 데이터는 현재 페이지의 메모리에만 있다. 새로고침·탭 종료 후 복구하지 않는다. 브라우저 저장소·실제 서버에 입력을 저장하지 않는다.
- 결과는 직접 입력한 발췌와 항목 정리다. 실제 AI가 내용을 추론하거나 요약했다고 표시하지 않는다. 말하지 않은 항목은 빈 상태로 둔다.
- 추천은 PRD 6.2의 후보 표를 fixture로만 사용한다. 대표 감정 기준이며 부가 감정 추천 우선순위·최종 매핑은 운영 계약에서 확정해야 한다.
- 결과 생성 요청은 대화 ID로 중복을 막는다. 성공한 경우에만 기록을 생성한다. 종류 개방 여부는 상담 결과와 무관하다[D34]. 체험하지 않아도 기록이 남는다. 저장 실패의 재시도 동안 입력은 유지한다.
- 기록 삭제는 예시 저장소와 Query 캐시에서 함께 제거한다. 삭제 실패 때 원 기록은 남긴다. 기록 삭제와 관계없이 세 종류 모두 선택 가능하다[D34].
- 월간 달력은 브라우저 현지 날짜 기준이며, 하루 여러 기록은 최신순으로 표시한다. 영속 API의 시간대·페이지네이션은 아직 확정하지 않았다.
- 말랑이는 Canvas 2.5D 조작이다. 슬랑이보다 스퀴시의 늘어남이 작고 입력 종료 후 3초 대기 뒤 각각 5초/3초로 복원한다. 왁뿌볼은 가까운 2영역씩 총 6회로 껍질을 깨뜨린다. 파괴 횟수·계수는 비교용 구현값이며 실제 재료/3D 물리 모델이 아니다.
- 말랑이 화면의 `type`은 진입 종류, 종류 선택은 대표 선택값을 바꾼다. 원 상담 추천은 별도 필드에 유지한다.
- 서비스 내 뒤로가기와 대화 끝내기는 기존 종료 분기를 따른다. 브라우저 자체 뒤로가기 정책은 별도 미정으로 유지한다.
- 모양 9개는 기존 세 종류 내부의 선택이다. 세 종류 모두 선택 가능하며 모양/음량은 실행 중 메모리에만 남는다. 사운드는 CC0 가공 녹음 9개와 다운로드 실패 시 합성 효과를 사용한다. 수면 ASMR은 구현하지 않았다.
- 대화 응답 형식 오류만 최대 한 번 자동 재요청한다. 동일 requestId를 유지하고 계속 실패하면 기존 오류/수동 재시도로 연결한다. 잘못된 기록·인벤토리는 화면을 깨뜨리는 대신 오류로 처리한다. 실제 AI 계약 검수는 남아 있다.

## QA 실행

`npm test`, `npm run build`, `npm run test:e2e`. Windows에서 브라우저 캐시와 임시 결과를 별도 드라이브에 둔 경우:

```powershell
.\scripts\qa.ps1 -RuntimeRoot 'E:\Ganzithon\tooling'
```

해당 경로의 `playwright` 폴더에 프로젝트 버전의 브라우저가 설치되어 있어야 한다. 테스트는 메모리 부담을 줄여 1 worker로 실행한다. 경로는 로컬 환경의 선택 사항이며 프로젝트의 필수 드라이브가 아니다. 정확한 실행 결과·실패 수정 이력은 [QA 검증 기록](qa.md)에 기록한다.

## 기능 보완 — 2026-11-14

- 결과 요청에 전체 대화 메시지를 포함한다. 실제 요약·원문 영속 저장은 하지 않는다.
- 공통 요청의 30초 제한 시간과 연결 실패/잘못된 JSON 안내를 추가했다. 재시도 시 보낸 메시지와 초안, 완료 draft를 유지한다.
- 대화 화면 이탈 시 대기 답변을 취소한다. 쓰기 요청의 취소를 실제 서버 작업 취소로 간주하지 않는다.
- 삭제/종류 선택 처리 중 팝업 닫기를 막고 실패 후 해제한다. 말랑이 조작 중 다중 포인터·초점/탭 이탈을 처리한다.
- 최신 검사 결과는 [QA 검증 기록](qa.md)의 가장 위 항목을 따른다. 위 48개/20개 결과는 이전 전체 흐름 연결 시점의 기록이다.

## 메인 대화 시트 — D30

메인의 감성/미리보기 문구와 큰 대화 CTA를 제거했다. `BottomSheet`는 앱 폭·가시 영역에 맞춰 열리고 닫기/Escape/배경/드래그·초점 순환을 지원한다. 시트의 첫 입력은 Context의 메모리 `entry`를 통해 인증 진입 이후 Chat에 전달한다. 빈 입력은 기존 첫 인사로 시작하며, 작성한 입력은 StrictMode에서도 한 번만 전송한다. 새로고침 저장·전체 대화의 시트 내 진행을 추가하지 않았다. 실제 API 상태는 이 문서와 requirements-status에서 계속 구분한다.


## 메인에서 바로 조작 — D31

`Home`은 말랑이 요소를 유지하면서 지역 `playing` 상태만 바꾼다. 배경·조작 컨트롤·대화 진입의 표시가 전환되고 첫 누름/드래그부터 반응한다. 종료 시 같은 말랑이에 초점을 복원한다. 숨은 UI는 inert 처리하고 바텀시트 초안을 보존한다.

`ToySurface`와 `useToyInteraction`을 메인과 기존 `/malangi` 경로가 공유한다. 추천 결과 진입과 종류 선택은 유지한다. D34에 따라 세 종류를 모두 개방한다. 비로그인 메인은 세 종류 모두 서버 쓰기 없이 로컬 선택·조작한다. 로그인 계정의 인벤토리는 기존 예시 API를 이용한다. D34 전체 개방 정책의 실제 백엔드 반영은 미검증이다. 경로 수는 9개로 유지하고 메인 상태를 추가 화면으로 세지 않는다.


## 결과·보관함·MY 시각 정렬 — D33 후속, 2026-11-15

Figma Design 속성에서 직접 읽은 카드·글꼴·간격을 `Records`와 `Account`에 반영했다. 공통 `Page.titlePlacement`는 상단 중앙/본문 좌측/접근성용 숨김 제목을 지원하며 페이지마다 h1 하나를 유지한다. 결과는 추천 카드/조언/후보/CTA/기록 링크 순서, 전체 항목과 점수는 이어서 표시한다. 보관함 제목은 본문 왼쪽, 상세는 흰 요약 카드 안에 점수·항목·대화 펼침을 포함한다. MY 프로필·행 치수는 원본에 맞추며 연결된 메뉴 기능은 유지한다.

- 원본 수치: [노드별 확인표](design/figma-inspection-2026-11-15.md)
- 사용자에게 요청한 PNG·SVG: [인계표](design/asset-handoff.md). 로고·수면 UI PNG는 수령했지만 미적용이며, 정식 말랑이 2D·석상·아이콘은 대기 중이다. 현재 임시 캐릭터·아이콘을 유지한다.
- 꾹꾹체는 메뉴뿐 아니라 동적 요약에도 지정되어 있어 단순 SVG 교체만으로 전체 서체를 일치시킬 수 없다. 웹 사용 허락 전 Pretendard를 유지한다.
- 추가 회귀 검사 `tests/design-layout.spec.ts`는 결과·보관함·상세·MY의360/390/430/844(가로)/1280px에서 가로 넘침·본문 높이·단일 h1·화면 캡처와 팝업 초점 복귀를 확인한다. 로딩 완료를 기다린 후 캡처한다. 실제 기기 검증을 뜻하지 않는다.
- 원본 잠금 하위 레이어 일부·그림자 세부·프로토타입 전환은 미확인. 백엔드 연결 상태나 제품 범위는 이번 스타일 작업으로 변경하지 않았다.

D34(2026-11-15): D34 적용 기준으로 세 종류를 처음부터 개방했다. 메인(비로그인 포함)·체험·결과에서 잠금 UI와 추천 해금 조건을 제거했다. 기존 추천 기록은 유지한다. 실제 서버의 잠금 정책은 아직 수정하지 않았으며 연동 시 맞춰야 한다.
