## 이전 적용 — D42: 설정 복귀와 결과 첫 화면 경계 (2026-11-16)

- 설정 진입 시 내부 출발 경로와 필요한 화면 상태를 함께 전달한다. 상단 뒤로가기는 출발 화면으로 복귀하며 보관함의 월간/주간/목록·기준 월·선택 날짜를 유지한다. 말랑이 종류 쿼리와 결과 기록 ID도 유지한다. 직접 설정 진입처럼 출발 정보가 없으면 메인으로 간다.

- 결과 첫 화면은 ‘저장된 기록 확인하기’까지 배치한다. 저장 완료 안내/상세는 다음 스크롤 영역에 둔다. 남는 높이는 추천 카드/그림에 배분하고 링크 아래에는 기본12px 여백과 기기 안전 여백만 둔다. 긴 내용은 스크롤을 유지한다.

## 이전 적용 — D39 (2026-11-16)

- **대화 진행:** 프론트 예시 응답의 사건 단어 목록/9자 제한을 제거했다. 보통 문장은 감정 선택으로 진행하고, 명백히 막연한 첫 문장은 한 번만 더 묻는다. 다음 의미 있는 답은 진행하며 ‘이 내용으로 계속하기’도 제공한다. 자음·기호만 입력하면 전송 전 입력창에서 안내하고 반복 AI 질문을 추가하지 않는다. 사용자 문장만 보관하며 서버의 사건 판단 규칙을 확정한 변경은 아니다.
- **종료 확인:** 보관은 진한 기본 버튼, 계속 대화는 테두리 버튼, 저장 없이 나가기는 구분선 아래 붉은 보조 동작이다. 감정 선택 후에는 점수 마무리도 유지한다. 저장 없이 나가기는 어떤 단계에서든 현재 대화를 보관하지 않고 메인으로 이동한다. 대화의 단계 캡션과 하단 ‘전문 상담이나 치료를 대신하지 않아요.’ 문구는 제거했다.
- **기록 상세:** Figma ‘마음 보관함 기록 선택’ 구성에 맞춰 요약·전후 점수·입력한 생각/실천을 한 카드에 넣고, 하단에 숨기기·삭제·자세히 보기를 배치한다. 상단 삭제와 외부 가리기 버튼은 제거했다. `?view=conversation`은 같은 기록의 전문 보기 상태이고 뒤로가기로 요약에 복귀한다. 가린 내용 보호·MY 복원·집계 제외는 유지한다. 없는 점수/관점/사용 이력은 생성하지 않는다.
- **메인 말풍선:** 투명 캔버스 경계 대신 양의 실제 보이는 상단을 기준으로 붙인다. 아이보리 둥근 면·작은 꼬리·얕은 그림자, 0.55초 등장과 4.8초 주기의 3px 떠오름을 적용한다. 호흡은 그림에만 적용해 클릭 영역을 고정하고 줄인 모션에서는 정지한다. 새 말풍선 모양/모션은 승인된 웹 보완안이며 Figma 원본 효과를 측정해 복제한 값은 아니다.
- **음성 경계:** 실제 사이드패널 브라우저에서 인식 서비스 `network` 오류를 재현했다. 시작 이벤트가 10초간 없으면 연결 대기를 끝내고, 결과 없는 종료의 자동 재시작은 1회로 제한한다. 오류 시 경과시간을 멈추고 초안을 보존하며 재시도/글로 계속하기를 제공한다. 브라우저 서비스 연결 실패 자체는 해결 확인되지 않았다. 실제 전사 성공·한국어 인식 품질과 가상 이벤트 QA를 구분한다.
- **범위:** 로그인 전체 흐름·수면은 변경하지 않았다. 실제 AI·인증·영속 DB/STT 백엔드 미연동, 기록은 현재 탭 메모리다. 독립 경로는 9개다. 노션/Figma 원본과 원격 Git은 수정하지 않는다.

## 이전 적용 — D38 (2026-11-16)

- **중간 보관:** 종료 확인창의 ‘여기까지 보관하고 나가기’는 전송한 사용자 메시지가 있을 때만 제공한다. 현재 대화·확정 감정·점수·슬롯을 그대로 저장하고 마음 보관함으로 이동한다. 감정 미선택도 허용하되 추천은 생성하지 않는다. 미입력 점수/슬롯을 채우지 않으며, 작성 중 글·미확정 음성은 저장하지 않는다. 저장 실패 시 대화를 유지하고 같은 ID/스냅샷으로 재시도한다. 정상 완료·사후 점수 경로도 유지한다.
- **기록 가리기:** 삭제와 별도다. 가린 기록은 월간·주간·목록·횟수/평균/감정 집계에서 제외한다. MY → 기록 관리 / 삭제 / 가리기에서 확인하고 다시 표시할 수 있다. 가린 상세는 내용 대신 안내를 먼저 보여주고 ‘이번에만 내용 보기’로 펼친다. 별도 잠금/암호 보호를 뜻하지 않는다.
- **말랑이 선택:** 추천받은 종류가 기본 선택이다. 후보를 누르면 같은 결과 화면의 강조·캐릭터·조작 안내·CTA만 바뀐다. ‘선택한 말랑이 만지러 가기’에서 이동하며 당시 추천 기록은 유지한다. ‘눌러서 바꿀 수 있어요’를 표시한다.
- **짧은 프론트 대화:** 기본 예시 경로는 OPEN → EMOTIONS → PRE → THOUGHT → ACTION → POST → DONE이다. REFRAME/NEED/COPING 타입과 기존 분기 처리는 남기지만 기본 체험에서 추가 질문하지 않는다. 건너뛴 슬롯은 미입력으로 유지한다. 이 변경은 서버 AI 단계 정책의 확정이 아니다.
- **화면:** 음성 석상은 상단 최소72px(낮은 화면64px)을 확보하고 메인 말풍선의 박스 기준 배치는 D39에서 실제 양 그림 기준으로 교체했다. 추천 카드/요약/후보/CTA는 고정 Y 대신 내용 높이를 따라 배치한다. 작은 조언은 산책·휴식·기록 각 3개 문구와 해당 원본 SVG를 연결하며, 사용자 실천이 있으면 그 문장을 우선한다.
- **경계:** 로그인 전체 흐름과 수면은 기존 임시 상태를 유지한다. 실제 AI·인증·영속 DB 미연동. 중간 저장 `partial`, 가리기 `hidden`, PATCH는 프론트 예시 계약이며 서버 지원을 의미하지 않는다. 새로고침하면 체험 기록은 초기화된다. 독립 경로 수는 9개이며 `/archive?manage=1`은 보관함의 관리 상태다.

## 시안 전용 가정 — 제품 확정과 분리

- 로그인은 실제 이메일/소셜 인증이 아니다. 두 개의 고정된 체험 프로필을 명시적으로 선택한다. 인증 방식과 가입 UX는 여전히 미정이다.
- 계정별 예시 데이터를 분리하기 위해 대화·체험·보관함·상세·결과 진입 시 체험 계정 선택을 요구한다. 메인·설정·도움은 공개한다. 이는 실제 로그인 요구 시점 확정이 아니다.
- MSW가 `/__preview__/` 요청을 처리하며 모든 데이터는 현재 페이지의 메모리에만 있다. 새로고침·탭 종료 후 복구하지 않는다. 브라우저 저장소·실제 서버에 입력을 저장하지 않는다.
- 결과는 직접 입력한 발췌와 항목 정리다. 실제 AI가 내용을 추론하거나 요약했다고 표시하지 않는다. 말하지 않은 항목은 빈 상태로 둔다.
- 추천은 PRD 6.2의 후보 표를 fixture로만 사용한다. 대표 감정 기준이며 부가 감정 추천 우선순위·최종 매핑은 운영 계약에서 확정해야 한다.
- 결과 생성 요청은 대화 ID로 중복을 막는다. 성공한 경우에만 기록을 생성한다. 종류 개방 여부는 상담 결과와 무관하다[D34]. 체험하지 않아도 기록이 남는다. 저장 실패의 재시도 동안 입력은 유지한다.
- 기록 삭제는 예시 저장소와 Query 캐시에서 함께 제거한다. 삭제 실패 때 원 기록은 남긴다. 기록 삭제와 관계없이 세 종류 모두 선택 가능하다[D34].
- 월간 달력은 브라우저 현지 날짜 기준이며, 하루 여러 기록은 최신순으로 표시한다. 영속 API의 시간대·페이지네이션은 아직 확정하지 않았다.
- 말랑이는 Canvas 2.5D 조작이다. 슬랑이보다 스퀴시의 늘어남이 작고 입력 종료 후 D46의 재질별 시간/곡선으로 복원한다. 왁뿌볼은 남은 영역별로 깨뜨리며 전체 제거 후 손을 떼면 자동 복원한다. 파괴 횟수·계수는 비교용 구현값이며 실제 재료/3D 물리 모델이 아니다.
- 말랑이 화면의 `type`은 진입 종류, 종류 선택은 대표 선택값을 바꾼다. 원 상담 추천은 별도 필드에 유지한다.
- 서비스 내 뒤로가기와 대화 끝내기는 기존 종료 분기를 따른다. 브라우저 자체 뒤로가기 정책은 별도 미정으로 유지한다.
- 모양 9개는 기존 세 종류 내부의 선택이다. 세 종류 모두 선택 가능하며 모양/음량은 실행 중 메모리에만 남는다. 사운드는 CC0 가공 녹음 9개와 다운로드 실패 시 합성 효과를 사용한다. 수면 ASMR은 구현하지 않았다.
- 대화 응답 형식 오류만 최대 한 번 자동 재요청한다. 동일 requestId를 유지하고 계속 실패하면 기존 오류/수동 재시도로 연결한다. 잘못된 기록·인벤토리는 화면을 깨뜨리는 대신 오류로 처리한다. 실제 AI 계약 검수는 남아 있다.

$qaRuntimeRoot = Join-Path $env:LOCALAPPDATA 'teslang-qa'

- 삭제/종류 선택 처리 중 팝업 닫기를 막고 실패 후 해제한다. 말랑이 조작 중 다중 포인터·초점/탭 이탈을 처리한다.

## 메인 대화 시트 — D30

## 메인에서 바로 조작 — D31

`Home`은 말랑이 요소를 유지하면서 지역 `playing` 상태만 바꾼다. 배경·조작 컨트롤·대화 진입의 표시가 전환되고 첫 누름/드래그부터 반응한다. 종료 시 같은 말랑이에 초점을 복원한다. 숨은 UI는 inert 처리하고 바텀시트 초안을 보존한다.

`ToySurface`와 `useToyInteraction`을 메인과 기존 `/malangi` 경로가 공유한다. 추천 결과 진입과 종류 선택은 유지한다. D34에 따라 세 종류를 모두 개방한다. 비로그인 메인은 세 종류 모두 서버 쓰기 없이 로컬 선택·조작한다. 로그인 계정의 인벤토리는 기존 예시 API를 이용한다. D34 전체 개방 정책의 실제 백엔드 반영은 미검증이다. 경로 수는 9개로 유지하고 메인 상태를 추가 화면으로 세지 않는다.


## 결과·보관함·MY 시각 정렬 — D33 후속, 2026-11-15

Figma Design 속성에서 직접 읽은 카드·글꼴·간격을 `Records`와 `Account`에 반영했다. 공통 `Page.titlePlacement`는 상단 중앙/본문 좌측/접근성용 숨김 제목을 지원하며 페이지마다 h1 하나를 유지한다. 결과는 추천 카드/조언/후보/CTA/기록 링크 순서, 전체 항목과 점수는 이어서 표시한다. 보관함 제목은 본문 왼쪽, 상세는 흰 요약 카드 안에 점수·항목·대화 펼침을 포함한다. MY 프로필·행 치수는 원본에 맞추며 연결된 메뉴 기능은 유지한다.

- 원본 수치: [노드별 확인표](design/figma-inspection-2026-11-15.md)
- 사용자에게 요청한 PNG·SVG: [인계표](design/asset-handoff.md). D35에서 일반 양·석상·로고를 적용했다. 종류별 최종 자산·별도 아바타·아이콘은 대기다.

메인 하단 시트와 우상단 4개 메뉴, 예시 AI 발화의 하오체, 보관함 주간·목록 레이아웃을 갱신했다. 주간 집계는 저장된 동일 기록의 전후 점수 쌍을 사용하며 누락을 0으로 대체하지 않는다. UI/집계 구현과 실제 서버·AI·DB 연동은 별개다. 원본 측정값과 웹 대응 차이는 [D36 기록](design/navigation-archive-2026-11-16.md), 실행 결과는 [QA](qa.md)에 기록한다.

## D37 대화·음성·화면 보완

시트와 직접 입력이 같은 텍스트를 한 번 전송하며 시작 문구도 표시값 그대로 보낸다. 로컬 OPEN은 보충 발화 이력을 참고하고 자음/모호한 문장에 똑같은 질문을 연속 반복하지 않는다. 실제 의미 분석은 여전히 미연동이다.

SC03 내부 음성 모드는 브라우저 인식의 중간 전사·확정 발화 전송, TTS·음소거·중단·채팅 전환을 제공한다. 화면 안 종료/뒤로가기는 확인창으로 연결한다. 운영 환경의 인식 서비스·실기기 검수는 남아 있다. 메인 짧은 말풍선·호흡·164px 메뉴 애니메이션과 결과의 발자국/작은 실천을 반영했다. 개발 안내와 오류 재현 UI는 제거하고 로그인·수면은 기존 임시 상태를 유지한다.

[원본 측정과 남은 임시 구현](design/dialogue-voice-2026-11-16.md), [인계](handoff.md), [QA](qa.md)를 함께 확인한다.
