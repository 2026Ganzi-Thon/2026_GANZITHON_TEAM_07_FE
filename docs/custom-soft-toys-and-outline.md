# 사진 말랑이 3종 · 둥근 형태와 투명 사진 윤곽

2026-11-20 PR #19 / main `39515a4` 웹 운영 배포 완료. [배포·QA 결과](custom-soft-web-release.md). APK는 별도 브랜치에서 관리.

## 현재 사용자 흐름

- 슬랑이·스퀴시·왁뿌볼 각각 모양 선택 마지막 `＋`에서 사진 만들기/관리.
- JPG/PNG/WebP 선택 → 둥근 형태 또는 사진 윤곽 → 만들고 만지기.
- 일반 사진은 둥근 형태로 확대/좌우/위아래 조절. 사진 윤곽은 배경이 투명한 사진에만 활성화.
- 사용자 피드백에 따라 **세 종류 모두 직접 지정, 점 찍기, 윤곽 완료 기능 제거**. 관련 컴포넌트·기하 코드·스타일도 제거.
- 왁뿌볼만 안쪽 색 선택. 사진 윤곽 안의 조각을 전부 깨뜨린 뒤 내부 조작, 휴지 후 껍질 복원.
- 슬랑이는 기존의 국소 늘림/복원과 움직임 소리, 스퀴시는 기존의 눌림/복원과 누름·복원 소리 사용. 임의 사진에는 양 얼굴 전용 표정 변형을 적용하지 않음.
- 저장 목록은 종류별 최대 6개. 수정·삭제·새로고침 후 다시 선택 가능. 현재 탭에서 종류를 전환해도 각 종류 선택을 유지. 선택한 사진 삭제 시 해당 종류 기본 모양으로 복귀.
- 이름 입력/별도 미리보기 페이지/보관 안내·개수 설명은 추가하지 않음.

## 데이터 호환

- 기존 IndexedDB 이름 `teslang-custom-wax`와 파일명 `customWax*` 유지. 타입 없는 이전 사진은 WAKPPU로 읽음.
- 직접 지정 실험에서 이미 저장한 사진은 삭제하지 않음. 읽을 때 완성된 투명 PNG를 편집 원본으로 사용하고 사진 윤곽 모드로 정규화. 새 저장에는 manual/점 좌표를 쓰지 않음.
- 개수 제한과 기존 항목 교체는 종류별 동일 readwrite 트랜잭션 안에서 처리. 사진은 기존과 같이 로컬 보관하며 서버 업로드 없음.
- 등록된 사진의 toyType으로 재질을 결정하고 선택 시 종류 일치를 검사. 기존 이미지 캐시/알파 판정/Blob URL 정리를 유지.
- 인증·상담·기록·수면 API 및 기록별 추천 모양 계약은 변경하지 않음.

## 검증

- 직접 지정 제거 후 운영 빌드, 단위 테스트 20개 파일/167개 통과.
- 브라우저 후속 검사는 세 종류 일반 사진/투명 사진 편집, 직접 지정 미노출, 이전 manual 사진 재조회·수정·저장을 확인. 실행 결과는 docs/qa.md 후속 항목 참고.
- 제거 전 수행한 22개 브라우저 시나리오는 이전 구현 검증 이력이며 직접 지정 기능을 현재 제공한다는 의미가 아님.
- 자동화 Chromium/WebKit 검증이며 실제 휴대폰 성능/청취 평가는 별도. 기존 음원은 변경하지 않음.
