# README 소개 이미지

2026-11-20 현재 프론트엔드 UI를 로컬 mock 모드에서 직접 촬영했다. 동일한 화면 컴포넌트를 사용하며, 대화와 기록은 소개용으로 만든 허구의 예시다. 실제 사용자 정보·이메일·인증정보를 포함하지 않는다. 점수는 효능을 입증하는 측정값이 아니다.

| 파일 | 내용 |
| --- | --- |
| cover.png | 기존 테슬랑 워드마크·양 스퀴시와 HTML/CSS 타이포그래피로 구성한 표지 |
| home.png | 메인 대기 화면 |
| chat.png | 예시 대화 후 감정 선택 화면 |
| archive.png | 예시 기록 5개의 주간 보관함 |
| sleep.png | 30분 타이머로 실행한 수면모드 |

화면 캡처는 390×844 CSS 픽셀, 2배 해상도다. 표지는 1440×640이다. 본문에서 사용하는 말랑이 원화는 public/assets/design의 기존 팀 제공 자산을 직접 참조한다. 별도 외부 이미지나 새로운 폰트는 추가하지 않았다. 자산 사용 조건은 [자산 안내](../assets.md)를 따른다.

개발용 캡처·렌더링 스크립트와 임시 미리보기는 저장소에 포함하지 않는다.
