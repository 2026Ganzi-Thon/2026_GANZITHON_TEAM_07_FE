## 업로드 범위와 남은 사항

- artifacts, QA 영상/캡처, 개인 작업 일지, .env.local, node_modules 및 dist는 Git 제외 상태를 유지한다.
- 녹화에서 추출한 왁스 음원3개는 로컬 비교용이며 공개 재사용 조건 미확인이다. public/dist/PR에 포함하지 않는다. 로컬 opt-in이 없으면 독립 합성음으로 동작한다.
- 꾹꾹체는 기존 적용을 유지한다. 이번 추천 문장만 Pretendard로 변경했다. 기존 서체 사용 조건 및 최종 교체 협의는 종전 인수인계대로 남아 있다.
- 로그인 전체 흐름·수면모드·실제 백엔드 연결은 기존 담당 범위를 유지한다. 실제 브라우저 음성 인식 서비스 연결 성공은 확인되지 않았다. UI/가상 전사 검수를 실제 한국어 인식 완료로 설명하지 않는다.
- 버터/하트는 비교 가능한 로컬 동작이며 공통 최종 사양은 선택 전이다. 단순 화면 변경과 해당 실험 범위를 구분해서 리뷰한다.
