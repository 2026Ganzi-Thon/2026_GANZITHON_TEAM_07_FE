# 대화 UI와 왁뿌볼 반동 — 2026-11-20

## 적용 범위

- 실제 상담 종료 팝업의 간격을 압축하고 주요 버튼 아래 나가기 영역을 구분했다. ‘아직 보내지 않은 글…’은 새 줄로 시작한다. ‘잠시 나가기’와 ‘저장 없이 나가기’는 같은 행이며 삭제 동작은 붉은색으로 구별한다.
- 종료 의도 전송, 사후 점수와 정상 완료, 탭 내 임시 이탈, 서버 abort 동작은 유지한다. 결과 문장을 프론트에서 재작성하지 않는다.
- 감정 확인 카드는 기본 접힘인 네이티브 details로 변경했다. 실제 상담에서는 제출 메시지 ID에 연결해 뒤의 대화가 늘어나도 같은 위치에 남는다. 펼침/접힘은 키보드로도 가능하다. 기존 탭 캐시에는 감정 요약 메시지 위치를 찾는 호환 처리를 둔다. mock 대화의 인라인 카드도 접을 수 있고 기록 상세의 전체 카드는 유지한다.
- 서버의 일반 단계명은 대화 상단에서 제거했다. 이후 수면 후속 작업에서 상단 응답 준비·마지막 마음 점수 문구도 제거했다. 메시지 영역의 응답 준비와 실제 오류 안내는 유지한다.
- 새 껍질이 깨질 때만 캔버스에 최대 가로 2px/세로 1.5px, 140ms의 작은 반동을 적용한다. 같은 깨진 지점이나 전체 파괴 후의 말랑한 조작에는 반복하지 않는다. 고정 프레임으로 입력 좌표를 계산해 시각 반동이 파괴 위치를 바꾸지 않게 했다. 종류 변경·이탈·포커스 상실·모션 감소 시 반동을 정리한다. 기존 물성·전체 파괴 후 조작·음원은 유지한다.

## 이어하기 진입: 후속 적용

기존 `ChatEntrySheet`는 진행 중 상담 여부와 관계없이 새 이야기 입력 폼을 표시했다. ‘잠시 나가기’는 상담을 계정별 탭 메모리에 남겨 두므로 재개와 새 시작이 구분되지 않는 문제가 있었다.

실제 상담에서 명시적으로 ‘잠시 나가기’를 선택한 대화에만 paused 표시를 붙인다. 같은 계정의 미완료 대화에 한해 ‘이야기를 이어갈까요?’ 시트가 나타난다. ‘이전 대화 이어하기’는 메시지 전송 없이 기존 로그와 작성 중 글을 복원하고 paused 표시를 해제한다. 완료·저장 없이 나가기·로그아웃에서는 기존 캐시 정리로 재개 항목이 사라진다. 새로고침 후 재개는 지원하지 않는다.

‘새 이야기 시작하기’는 기존 대화/미전송 글을 저장 없이 종료한다는 확인 화면을 연다. ‘이전 대화 유지하기’ 또는 창 닫기는 서버에 요청하지 않는다. 명시적으로 확인하면 기존 abort API 성공 후에만 로컬 대화 상태를 비우고 새 이야기 입력창을 연다. 새 세션은 그 입력을 전송할 때 생성한다. 응답 대기에는 중복 확인과 시트 닫기를 막고, 실패하면 캐시를 보존하며 자동 재요청/새 세션 생성을 하지 않는다. 기존 캐시의 구독자에게 빈 상태를 명시적으로 알리도록 setQueryData(null)을 사용한다.

감정 카드의 글자 화살표는 18px Lucide ChevronDown SVG로 교체했다. 가운데 정렬·일관된 선 두께를 사용하며 열면 회전하고 모션 감소 설정에서는 전환 애니메이션을 생략한다.

추가 서버 API·백엔드 수정 없이 기존 종료 API를 재사용했다. 결과 문장·수면·로그인 동작은 변경하지 않았다. PR·병합·배포 전 로컬 검토 상태다.

## 검증

빌드와 단위 155개 통과. 이어하기/새 시작 확인까지 확장한 Chromium/WebKit 16개 시나리오를 검증했다(전체 실행 15개 + 요청 도착 대기 assertion을 보완한 WebKit 1개 재검사 통과). 제어된 API 응답으로 UI·통합 동작을 검증했으며 실제 AI 품질/실제 휴대폰 검증과 구분한다. 상세 근거는 [QA](qa.md)의 최신 항목을 따른다.
